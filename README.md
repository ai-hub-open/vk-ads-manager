# Пакет для ВК Реклама

`vk-ads-manager` — скилл для подготовки и ведения кампаний в новом кабинете ВК Рекламы. ИИ-агент собирает бриф, разбирает конкурентов, проектирует аудитории, считает прогноз, готовит креативы и загружает структуру кампании в кабинет.

> **Первичная загрузка выполняется на паузе.** Кампанию проверяет и активирует человек.

У пакета два режима: подготовка кампании с нуля и ведение уже активной — статистика, бюджеты, статусы, аудитории, замена креативов.

## На чём стоит маршрут

Языковая модель охотно придумает красивые аудитории вроде «любителей сигар» — в кабинете ВК таких настроек нет. Маршрут пакета опирается на то, как устроен новый кабинет, и на приёмы, которые в нём работают:

- **Структуру задаёт матрица «теплота × персона»,** а не список идей. Сегменты выводятся из портретов покупателей и стадии готовности, и каждый становится группой — поэтому связка «гипотеза → аудитория → креатив» прослеживается до объявления.
- **Семантика в ВК — не парсинг тысяч ключей.** Для горячего сегмента берётся 15–40 точных фраз: это потолок, за которым таргетинг размывается. Приёмы из контекстной рекламы сюда осознанно не переносятся.
- **Прогноз считается по трём сценариям,** и у каждой цифры помечен источник: из кабинета, от рекламодателя или предположение. Лиды и цена лида попадают в стратегию только после отдельного согласования — чтобы оценка не превратилась в обещание.
- **Тексты проходят проверку до загрузки:** лимиты полей, капс, восклицания, триггеры модерации, сравнения по статье 5 закона о рекламе, упоминания конкурентов.
- **Показы включает человек.** Объекты создаются со статусом паузы, а удаление заменено остановкой: скилл не удаляет сущности в кабинете.

Перед запуском собирается предзапусковой чек-лист — пиксель, события, ссылки, тексты, маркировка. Методики этапов лежат в [`references/`](references/): двадцать четыре справочника по форматам, модерации, аудиториям, лид-формам, каталогам и продвижению приложений.

## Как проходит работа

Скилл создаёт рабочую папку кампании и сохраняет результат каждого шага отдельным файлом. Подготовка делится на четыре части.

**Рынок и смысл.** Бриф, материалы бренда, поиск и разбор конкурентов, их реклама и повторяющиеся приёмы, позиционирование и УТП по сегментам.

**Аудитории.** Портреты покупателей, матрица «теплота × персона», проверка пикселя и событий на сайте.

**Прогноз и креативы.** Проверка посадочной страницы, три сценария бюджета, тексты и визуалы по ключевым связкам. Изображения, короткие видео и PDF-лид-магниты агент генерирует при заданных ключах сервисов генерации.

**Загрузка.** Структура кампании заводится в кабинете через MCP-сервер ВК Рекламы, встроенный REST-клиент или по готовой инструкции, если доступа к API нет. Все объекты — на паузе.

На узловых развилках агент показывает результат и ждёт подтверждения: список конкурентов, позиционирование, матрица аудиторий, прогноз, креативы и сам запуск проходят через маркетолога.

## Ведение активной кампании

Второй режим — тринадцать готовых сценариев: сводка за период и ежедневная проверка, изменение бюджета, пауза и запуск, добавление аудиторий, загрузка своей базы контактов, замена креативов и таргетинга, недельный разбор со списком изменений, смена стратегии ставок, копирование кампании.

Перед изменением агент показывает план и ждёт подтверждения. После изменения перечитывает объект и записывает операцию в журнал.

## Что входит в пакет

### Подготовка и отчёты

| Скрипт | Назначение |
|---|---|
| `forecast.py` | прогноз по трём сценариям с пометкой источника каждой цифры |
| `generate_ads_xlsx.py` | таблица объявлений и проверка ограничений |
| `generate_media_plan.py` | единый документ по материалам кампании |
| `generate_strategy_report.py` | отчёт-стратегия для команды или рекламодателя |
| `vk_pixel_helper.py` | код пикселя и перечень событий |

### Генерация материалов

| Модуль | Результат | Ограничение |
|---|---|---|
| Изображения | PNG для объявлений и лид-магнитов | снимки интерфейса продукта лучше брать у рекламодателя |
| Видео | короткие MP4 и склейка сегментов | звук и титры добавляются отдельно; для склейки нужен FFmpeg |
| PDF | лид-магниты из Markdown | отправку получателю настраивает рекламодатель |

Генерация изображений использует OpenAI Images API. Для видео доступны Runway, Kling, Veo и Replicate; конкретный сервис и модель выбирает человек.

### Загрузка

| Скрипт | Назначение |
|---|---|
| `deploy_campaign.py` | загрузка медиа и создание кампании, групп и объявлений |
| `vk_ads_api.py` | работа с API ВК Рекламы и предстартовая проверка маркировки |
| `generate_launch_guide.py` | инструкция для ручной загрузки |
| `setup_vk_ads_mcp.py` | подключение хостового MCP-сервера `vk-ads` (Cursor / Claude Code / Claude Desktop) |

Для работы через MCP используется хостовый сервер [`vkads-mcp.aihub.click.ru`](https://vkads-mcp.aihub.click.ru) (код — [`ai-hub-open/vk-ads-mcp`](https://github.com/ai-hub-open/vk-ads-mcp)). Подключение: `python -m scripts.setup_vk_ads_mcp --token <CLICK_RU_TOKEN> --vk-account-id <ID> --target all`, подробности — [`docs/hosted-mcp-setup.md`](docs/hosted-mcp-setup.md) и `references/vk-ads-mcp-integration.md`.

### Справочники

В `references/` лежат методики по конкурентам, портретам покупателей, аудиториям, объявлениям, прогнозированию, посадочным страницам, изображениям, видео, PDF, API, модерации, маркировке рекламы, лид-формам, каталогам, приложениям и медийным форматам.

## Терминология API

В интерфейсе и API одни и те же уровни называются по-разному:

| В интерфейсе ВК Рекламы | В API |
|---|---|
| Кампания | `ad_plan` |
| Группа объявлений | `campaign` |
| Объявление | `banner` |

Группа `campaign` без `ad_plan_id` становится «сиротой» и не видна в новом кабинете. Пакет создаёт кампанию сразу со связанными группами и объявлениями.

## Что делает агент, а что остаётся человеку

**Агент:**

- ведёт маршрут и запускает скрипты;
- исследует конкурентов и готовит портреты покупателей;
- проектирует аудитории и креативы;
- считает прогноз и собирает отчёты;
- создаёт структуру в кабинете;
- проверяет ограничения текстов и ведёт журнал изменений.

**Человек:**

- подтверждает конкурентов, позиционирование, аудитории и прогноз;
- проверяет изображения, видео и PDF;
- передаёт реквизиты для маркировки рекламы;
- устанавливает пиксель на сайт;
- предоставляет реальные снимки интерфейса и видео с людьми;
- проверяет и активирует кампанию.

## Ограничения

- Пакет не расходует бюджет без явного запуска человеком.
- При ведении он не удаляет сущности, а ставит их на паузу.
- Данные без источника не выдаются за факт; лиды и CPL не попадают в стратегию без согласования.
- Пиксель и события устанавливаются на сайте вручную.
- Собственный REST-клиент не создаёт похожие аудитории и не загружает базу CRM при первой загрузке.
- Пакет работает только с новым кабинетом ВК Рекламы.
- Прохождение модерации и присвоение ERID зависят от платформы.
- Реальные снимки интерфейса продукта и готовые ролики с людьми предоставляет рекламодатель.

## Требования

- Python 3.9 или новее;
- доступ к ВК Рекламе;
- токен ВК Рекламы или API-токен click.ru для хостового MCP-сервера `vk-ads`;
- реквизиты рекламодателя для маркировки;
- API-ключи сервисов генерации изображений или видео — тех, что используются в работе.

## Установка

### Из исходников

Скачайте репозиторий, откройте его папку и запустите:

```bash
python install.py
```

Скрипт установит зависимости, создаст локальное хранилище ключей и проверит основные модули.

### Готовый файл скилла

Архив `vk-ads-manager.skill` собирается командой `./package.sh` в корне репозитория. Его можно загрузить в среду, которая поддерживает установку скиллов, либо распаковать вручную. Готовый архив есть и в разделе релизов на GitHub — стоит проверить, что версия там совпадает с `CHANGELOG.md`.

После установки напишите агенту:

> Хочу подготовить кампанию в ВК Рекламе для [продукт], бюджет [сумма], срок теста [период].

## Доступы

Ключи хранятся в `~/.vk-ads-manager/credentials.json`. На Unix файл получает права `600`.

Сохраняйте ключи через скрытый интерактивный ввод, чтобы они не попадали в историю команд:

```bash
python -m scripts.manage_credentials set vk_ads
python -m scripts.manage_credentials set openai
```

Посмотреть сохранённые сервисы:

```bash
python -m scripts.manage_credentials list
```

Удалить ключ:

```bash
python -m scripts.manage_credentials delete openai
```

Не передавайте секреты в открытом виде в README, задачах, журналах и файлах кампаний.

## Безопасность

- ключи хранятся отдельно от папки скилла и рабочих файлов;
- рабочие папки кампаний не входят в пакет;
- первичная загрузка создаёт объекты на паузе;
- перед изменением активной кампании агент должен показать план и дождаться подтверждения;
- перед запуском проверьте маркировку, бюджет, ссылки, пиксель и события;
- перед важной загрузкой проверьте имена полей API на тестовом объекте.
