# PDF lead magnet (M3)

Модуль M3 — генератор PDF lead magnets для eBook-креативов (главная ставка стратегии для конверсионных кампаний — 40% бюджета).

## Когда использовать

- После Шага 10 (есть creatives.json с eBook-креативами — формат `carousel_with_lead_form` или name содержит `ebook`).
- Желательно после Шага 10.5 — переиспользуем сгенерированные через M1 обложки и CTA-карточки.

## Архитектура

```
vk-campaign-<slug>/
├── creatives.json                  ← eBook-креативы (формат carousel_with_lead_form)
├── brand.json                      ← цвета, имя продукта
└── assets/
    ├── images/                     ← (от M1) обложки и CTA-карточки
    │   ├── <name>_card1.png        → cover PDF
    │   └── <name>_card3.png        → CTA финальная страница
    ├── pdf_content/                ← markdown контент (создаёт Claude в чате)
    │   ├── cr_ebook_p1.md
    │   └── cr_ebook_p2.md
    └── pdfs/                       ← готовые PDF
        ├── cr_ebook_p1.pdf
        └── cr_ebook_p2.pdf
```

## Workflow (для модели)

### Шаг 1. Узнать какие PDF нужны

```bash
python -m scripts.generate_lead_magnet_pdfs --workspace <path> --list-expected
```

Покажет какие eBook-креативы есть в creatives.json и ждут ли markdown-контент.

### Шаг 2. Написать контент в чате (Claude + пользователь)

Для каждого eBook-креатива Claude **в диалоге с пользователем** пишет полезный, конкретный, проверяемый контент:

- Структура: вступление → 5-7 разделов с конкретикой → CTA
- Объём: 5-10 страниц A4 (примерно 1000-2000 слов markdown)
- Тон: экспертный, без воды, с цифрами и кейсами
- В конце — CTA на сайт продукта с UTM-меткой

Сохраняет результат через `Write` в `assets/pdf_content/<creative_name>.md`.

**Шаблон markdown:**

```markdown
# Заголовок PDF (для обложки если нет картинки)

## Введение

Кому эта PDF: кратко описание ЦА.

В PDF разберём:
- Тема 1
- Тема 2
- ...

---

## Раздел 1: Конкретная тема

Текст с конкретикой и цифрами.

### Пример

Конкретный кейс или шаг.

- Точка 1
- Точка 2

---

## Раздел 2: ...

(и так далее 5-7 разделов)

---

## Что делать дальше

Подытожь и направь на конкретное действие.
```

`---` создаёт разрыв страницы. Это позволяет аккуратно разводить разделы.

### Шаг 3. Сборка PDF

```bash
python -m scripts.generate_lead_magnet_pdfs --workspace <path>
```

Что произойдёт:
1. Для каждого eBook-креатива проверит наличие markdown в `assets/pdf_content/`
2. Если есть — соберёт PDF
3. Если есть `<name>_card1.png` — используется как обложка вместо генерируемой
4. Если есть `<name>_card3.png` — используется как финальная CTA страница
5. PDF сохраняется в `assets/pdfs/<name>.pdf`

### Шаг 4. Ревью с пользователем

Покажи PDF через computer:// ссылку. Если контент нужно править — Claude меняет markdown, перезапускает с `--force`.

## Поддержка markdown

Скрипт поддерживает минимальное подмножество markdown:

- `# H1`, `## H2`, `### H3` — заголовки
- параграфы текста — обычным абзацем
- `**bold**`, `*italic*` — инлайн форматирование
- `- bullet` или `* bullet` — маркированные списки
- `1. numbered` — нумерованные
- `> blockquote` — цитата (с акцентным цветом)
- `---` или `***` — разрыв страницы
- `![alt](path)` — embed картинки (относительные пути от рабочей папки)

Не поддерживается:
- Таблицы markdown (используй визуальные раскладки в раздельных разделах)
- HTML внутри markdown
- Inline ссылки `[text](url)` — пиши ссылку текстом или через CTA

## Брендинг

Из `brand.json` берётся:
- `primary_color` — фон обложки + цвет заголовков H1/H2
- `accent_color` — цвет финальной CTA-страницы + акценты
- `product_name` — имя в обложке и футере
- `neutral_dark` — цвет основного текста

## Чек-лист PDF перед использованием

- [ ] Markdown написан в `assets/pdf_content/<creative>.md`
- [ ] Тон экспертный, есть конкретика и цифры
- [ ] Нет «воды» в духе «качество и индивидуальный подход»
- [ ] 5-10 страниц (1000-2000 слов)
- [ ] Каждый раздел заканчивается чем-то конкретным (примером, шагом, инсайтом)
- [ ] CTA в конце ведёт на сайт продукта с правильным UTM (берётся из creatives.json url)
- [ ] (опционально) есть обложка `<name>_card1.png` от M1
- [ ] PDF собран, ревью пройден, размер < 5 MB

## Связь с другими модулями

- **M1 картинки** — обложки и финальные CTA-страницы переиспользуются из `assets/images/`
- **M4 deploy** — после генерации PDF можно повышать ставки на eBook-креативы через UI («скачивайте PDF», авто-отправка на email через лид-форму VK или через email-сервис клиента)
- **Email-цепочка** — после получения email через лид-форму VK, клиент настраивает прогрев в своей CRM/email-сервисе (Mindbox / SendPulse / Unisender) — это вне скилла, но важная часть стратегии
