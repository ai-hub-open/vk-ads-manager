# Подключение MCP-сервера «VK Реклама»

Скилл работает с кабинетом через официальный MCP-сервер организации: <https://github.com/ai-hub-open/vk-ads-mcp> — 48 операций: кампании, группы, объявления, аудитории, бюджеты, статистика.

## Режимы подключения

- **Через Click.ru — основной путь**: токен из профиля click.ru (`CLICK_RU_TOKEN` + `CLICK_RU_ACCOUNT_ID`); сервер сам получает и обновляет токен ВК.
- Готовый токен ВК Рекламы: `VK_ADS_ACCESS_TOKEN`.
- OAuth-приложение с target.vk.ru: `VK_ADS_CLIENT_ID` + `VK_ADS_CLIENT_SECRET` (есть режим агентства от имени клиента).

Подробности, лимиты и примеры конфигурации — в README сервера.

## Установка

Автоматически: `python scripts/setup_vk_ads_mcp.py` — клонирует официальный репозиторий, проверяет Bun, ставит зависимости и регистрирует сервер в конфигурации агента. Вручную — по README сервера: `bun install`, запуск `bun run src/index.ts`, переменные окружения одного из режимов выше.

После подключения проверьте связь инструментом `vk_ads_auth_check`.
