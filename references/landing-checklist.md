# Лендинг — чек-лист готовности к VK Реклама

Перед запуском платного трафика на лендинг — пройти этот чек-лист. Без него можно слить бюджет на сырой UX.

## Технический чек-лист

- [ ] **Скорость на мобиле:** Lighthouse Performance ≥ 70. Если < 60 — тормозит, конверсия упадёт.
- [ ] **Адаптивная вёрстка:** проверено на iPhone (Safari) и Android (Chrome) на разных разрешениях.
- [ ] **HTTPS:** обязательно. HTTP-сайт не пройдёт модерацию VK.
- [ ] **Корректный favicon и og-теги** — превью в превью будет красивым.
- [ ] **Нет JS-ошибок** в консоли DevTools.
- [ ] **Cookie-баннер не закрывает контент** на мобиле первый экран.

## Контент чек-лист

- [ ] **H1 совпадает с обещанием в рекламе** — не просто похоже, а именно «то самое, что обещали».
- [ ] **Первый экран:** заголовок + подзаголовок + CTA + образ продукта. Без скролла понятно что это.
- [ ] **Доказательства:** логотипы клиентов / отзывы / цифры результатов / сертификаты.
- [ ] **Цена / условия:** видна без скролла или явная CTA «узнать цену».
- [ ] **Форма выше первого скролла** (или яркая CTA-кнопка ведущая к ней).
- [ ] **Юр.инфо в футере:** ИП/ООО + ИНН + контакты + ссылка на политику ПДн.
- [ ] **Политика обработки ПДн** — отдельная страница, ссылка из футера и из формы.
- [ ] **Без RU-блоков на EN-версии** (и наоборот) — если у вас многоязычный сайт.
- [ ] **Цены в правильной валюте** (RUB для российских кампаний).

## Конверсионный чек-лист

- [ ] **Пиксель VK Ads установлен** на всех страницах в `<head>`.
- [ ] **События пикселя настроены:** минимум `page_view`, `lead`, `purchase` (или регистрация для SaaS).
- [ ] **Цели в кабинете VK Реклама** замаплены на события пикселя.
- [ ] **UTM-метки** на финальных URL: `utm_source=vk_ads`, `utm_medium=cpm`, `utm_campaign=<slug>`, `utm_content=<creative_id>`.
- [ ] **Форма отправляет лид в CRM / на почту** — проверено реальной отправкой.
- [ ] **Спасибо-страница** или вспышка «Заявка отправлена» — пользователь понимает что всё сработало.
- [ ] **Спасибо-страница имеет URL** (для пикселя — событие `lead` на `thank_you_page`).
- [ ] **Forms не требуют лишних полей** — на старте только phone (или email), остальное на втором шаге.

## Доверие / соответствие

- [ ] **Контакты доступны:** телефон / email / соцсети / адрес офиса (если есть).
- [ ] **Юр.лицо указано** — ИП Иванов И.И., ИНН ... (или ООО).
- [ ] **Оферта / договор оферты** доступна (для платежей).
- [ ] **Возврат / гарантия** — описаны условия.
- [ ] **Согласие на обработку ПДн** в форме — чекбокс с ссылкой на политику.
- [ ] **Для медицины:** дисклеймер о противопоказаниях.
- [ ] **Для инвестиций:** дисклеймер о рисках.
- [ ] **Для образования:** информация о лицензии (если есть).

## Психология / UX

- [ ] **Главный оффер понятен за 5 секунд** — открой случайному человеку, спроси «что тут продают?».
- [ ] **Социальное доказательство видно** — отзывы / число клиентов / награды.
- [ ] **Возражения закрыты:** «А что если не понравится?», «А вы точно сделаете?», «А сколько стоит?» — ответы есть на странице.
- [ ] **Призыв к действию ясный** — не «попробовать», а «получить демо», «записаться на консультацию», «купить за 100₽ на старте».
- [ ] **Один основной CTA** — не 5 разных по странице.

## Region-checklist (если регионы кампании = РФ)

- [ ] **Цены в рублях**, не в USD/EUR.
- [ ] **Контактные данные** — телефон в формате +7 (российский).
- [ ] **Часы работы** — указаны и в МСК.
- [ ] **Юр.лицо российское** (или с российским ИНН для иностранных через агента).
- [ ] **Сайт открывается без VPN** из РФ (важно — некоторые CDN заблокированы).
- [ ] **Платёжные методы российские** — карты МИР, СБП.

## Red flags — стоп-список

Если есть хоть один из этих пунктов, **не запускать** до фикса:

- 🛑 **Сайт открывается > 5 секунд на мобиле** — отвалятся 50%+ юзеров.
- 🛑 **Форма не работает** — пиксель не зафиксирует конверсию.
- 🛑 **Главный оффер непонятен** — деньги в трубу.
- 🛑 **Нет пикселя** — нет оптимизации, нет ретаргета.
- 🛑 **Цены в неправильной валюте** — конверсия падает в 2-3 раза.
- 🛑 **Юр.инфо отсутствует** — модерация VK заворачивает или штраф ОРД.
- 🛑 **Запрещённые формулировки** на лендинге («100% гарантия», «лучший в России») — модерация VK не пройдёт.
- 🛑 **Сайт на иностранной CDN** заблокирован в РФ.

## Если что-то из этого нельзя пофиксить

**Лид-форма VK** — альтернатива лендингу. Пользователь не уходит из VK, заполняет форму прямо в приложении. Используется когда:
- Лендинг сломан / медленный / нет ресурсов править
- Простой продукт без длинной воронки
- Мобильный трафик (форма VK работает в приложении нативно)
