# VK Реклама — Правила и модерация (расширенный справочник)

> Углублённый разбор поверх базового блока модерации из vk-ads-specs.md. Здесь — детали по вертикалям, формулировкам, дисклеймерам и спец-случаям, которые определяют, пройдёт ли конкретное объявление проверку. Каждый пункт со слагом источника: `documents/moderation` (основные Правила, ред. 11.03.2026), `documents/faq_moderation` (разъяснения с примерами), `documents/required_documents` (перечень документов по вертикалям).
>
> Используй этот файл при подготовке текстов/креативов к заливу через MCP — как чек-лист «чтобы не словить отказ», а не как замену чтения самих Правил.

---

## 1. Как устроена проверка (коротко)

- Все объявления проходят **предмодерацию** перед стартом показов; после запуска возможна **постмодерация** — VK вправе отклонить уже одобренное объявление без объяснения причин (`documents/moderation` п.6).
- Любое редактирование текста/креатива/ссылки отправляет объявление на **повторную проверку** — учитывай это при срочных правках дат акций (`documents/faq_moderation`).
- Точных SLA по времени модерации VK публично не даёт — только рекомендацию планировать запуск заранее и не рассчитывать на мгновенное одобрение, особенно для категорий «по документам» (`documents/required_documents`: «проверка документов может занимать некоторое время»).
- Систематическое грубое нарушение правил или подмена страницы после модерации (редирект на запрещённый контент) — основание для **блокировки кабинета** и штрафа до 100 000 ₽ (`documents/moderation` п.7).
- Документы на категорию отправляются в поддержку VK **один раз** при первом запуске — дальше кампании по этой вертикали проходят быстрее (`documents/faq_moderation`).

## 2. Полный запрет (без вариантов «принести документы»)

Источник: `documents/moderation` п.3, п.3.1–3.5.

- Алкоголь, спиртосодержащая продукция, средства для изготовления алкоголя
- Табак, вейпы, электронные сигареты, испарители, кальяны, курительные принадлежности, сигаретная бумага
- Наркотические средства, психотропные вещества, средства их употребления
- Продукция военного назначения и оружие: боевое, служебное, гражданское (включая самооборону), спортивное с дульной энергией свыше 3 Дж, охотничье, сигнальное; поражающие элементы, патроны, магазины, глушители
- Взрывчатые вещества и материалы (кроме пиротехники)
- Казино, тотализаторы, любые игры на риске и пари — **исключение только покер** как интеллектуально-коммерческая игра
- Финансовые пирамиды, кассы взаимопомощи, сервисы «быстрого заработка»
- Товары для взрослых: порнография, интим-товары, эскорт, сервисы поиска партнёров для интимных услуг, пикап-тренинги
- Медицинское прерывание беременности; рецептурные лекарства; рецептурные/сложные контрацептивы (спирали и т.п.)
- Анаболические стероиды и аналоги
- Органы и/или ткани человека как объект купли-продажи
- Подделки, копии, реплики товаров (в т.ч. любые формулировки «реплика», «копия», «фейк», «неотличим от оригинала»)
- Эзотерика: маги, экстрасенсы, колдуны, тарологи, гадалки, экзорцисты, целители, хироманты, НЛП; магические амулеты и талисманы с заявленными «свойствами»
- Знакомства с явным сексуальным подтекстом («секс-знакомства», «на одну ночь», «интимный чат»)
- Продажа SIM-карт без агентского договора (см. раздел «по документам» — там же), SMS-услуги и платные подписки как объект рекламы
- Услуги по написанию дипломов, диссертаций, ВКР и прочих аттестационных работ
- ПО для подмены номера при звонках/SMS
- Продажа/розыгрыш игровой валюты и игровых предметов, читы, буст аккаунтов, реклама сторонних игровых серверов
- Экстремистские материалы, лица, организации, ресурсы; организации из списка ЦБ РФ с признаками нелегальной деятельности на финрынке
- Политическая агитация вне периода официальной предвыборной кампании (сравнение партий, реклама политиков, митингов и т.п.)
- Криптовалюта как **средство платежа** за товары/услуги (в т.ч. NFT) — сама реклама крипто-инструментов не под полным запретом, см. раздел 8

## 3. «По документам» — категория → что отправить в поддержку

Полный документ: `documents/required_documents` (~40 вертикалей). Ниже — основные направления с конкретными документами. Документы шлются в чат поддержки VK один раз на кабинет/вертикаль.

| Категория | Обязательные документы |
|---|---|
| **Аптеки** | ОГРН/ОГРНИП, лицензия на фармдеятельность, гарантийное письмо (декларации/сертификаты). Для «интернет-аптека»/«доставка день в день» — доп. разрешение Росздравнадзора |
| **Лекарственные средства** (в т.ч. ветеринарные) | ОГРН/ОГРНИП, регистрационное удостоверение препарата, сертификат соответствия (если выпущен до 29.11.2019) или пакет для препаратов после этой даты (инструкция, рег.удостоверение, подтверждение соответствия), лицензия на производство/фармдеятельность, гарантийное письмо |
| **БАДы** | ОГРН/ОГРНИП, несколько деклараций/сертификатов на продукцию, гарантийное письмо. Обязателен дисклеймер «БАД. Не является лекарственным средством» (≥10% площади) и таргетинг 18+ |
| **Медицинские учреждения / услуги врачей** | Лицензия на медицинскую деятельность; для врача лично — ещё скан трудового договора с клиникой или ссылка на сайт клиники с этим врачом |
| **Медицинская техника / медизделия** | ОГРН, регистрационное удостоверение на каждую единицу техники/изделия, лицензия на производство и техобслуживание (если рекламируется производитель), гарантийное письмо. Реклама изделий класса риска **2б и 3 запрещена полностью**, допустим только класс 1 и 2а |
| **Косметология (лицензируемые процедуры)** | Лицензия на медицинскую деятельность. Полный список процедур, требующих лицензии: ботокс/диспорт/рестилайн, мезотерапия, аппаратный пилинг, лазерная шлифовка, RF/SMAS-лифтинг, криотерапия, коррекция рубцов, аппаратная эпиляция и др. — см. `documents/required_documents#cosmetic_service`. Не требуют лицензии: маникюр/педикюр, шугаринг/воск, микроблейдинг, перманентный макияж, солярий, чистка лица |
| **Ветклиники** | ОГРН/ОГРНИП, документы о квалификации ветеринаров; для ИП — свидетельство регистрации в службе ветнадзора; при продаже ветпрепаратов — доп. лицензия Росздравнадзора |
| **Диетология / нутрициология** | Лицензия на медицинскую деятельность — только если специалист работает с заболеваниями (РПП, булимия, ожирение); чистая коррекция питания лицензии не требует |
| **Психотерапия, гипнотерапия** | Лицензия на медицинскую деятельность. Психология (без лечения) и клиническая психология без психотерапии — **без документов**. НЛП и валеология — под полным запретом |
| **Финуслуги / банки / брокеры** | ОГРН/ОГРНИП, лицензия ЦБ РФ (или профильная: брокерская/дилерская/депозитарная/УК), для посредников — лицензия партнёра + гарантийное письмо о посреднической роли |
| **Кредиты / МФО / ломбарды** | Для МФО — свидетельство из реестра МФО; для ломбарда — ОГРН (+ учёт в пробирной палате при операциях с драгметаллами); дисклеймер о ПСК обязателен (см. раздел 5) |
| **Форекс-дилеры** | ОГРН, лицензия профучастника рынка ценных бумаг на форекс-деятельность или брокера, членство в СРО форекс-дилеров. Название на лендинге должно совпадать с лицензией |
| **Бинарные опционы** | ОГРН/ОГРНИП + одна из лицензий (дилерская/по управлению ЦБ/брокерская/решение о выпуске ЦФА/лицензия профучастника). Запрещено обещать быстрый заработок |
| **Страхование** | ОГРН/ОГРНИП, лицензия на осуществление страхования; для посредников — гарантийное письмо об исключительно посреднических услугах |
| **Застройщики / недвижимость** | ОГРН, разрешение на строительство, ссылка на проектную документацию |
| **Лотереи, стимулирующие мероприятия** | ОГРН/ОГРНИП + (для лотерей) уведомление в госорган о проведении лотереи или разрешение на её проведение. Обязателен таргетинг 18+ |
| **Благотворительность** | ОГРН, банковские реквизиты сбора, устав фонда с указанием некоммерческого статуса. Сбор на частные счета запрещён |
| **Автошколы** | ОГРН, скан лицензии автошколы |
| **Образовательные учреждения** (школы, колледжи, курсы с дипломом/сертификатом) | ОГРН, лицензия на образовательную деятельность; для школ/колледжей — ещё документ об аккредитации |
| **Ювелирные изделия** | ОГРН/ОГРНИП, свидетельство постановки на учёт в Пробирной палате, сертификат соответствия для огранённых камней |
| **Банкротство** | ОГРН/ОГРНИП, статус самозанятого (юруслуги), членство в ассоциации арбитражных управляющих или удостоверение адвоката. Запрет гарантий 100% списания долга + обязательный дисклеймер (см. раздел 8) |
| **Изделия, похожие на оружие** (сувенирные ножи, арбалеты до 43/27 кг силы дуги, пневматика ≤3 Дж, страйкбол/пейнтбол) | ОГРН/ОГРНИП, сертификат на продукцию, заключение о «схожести с оружием, но не являющемся им», гарантийное письмо |
| **Тиры, стрелковые клубы** | Лицензия на приобретение оружия (или на образовательную деятельность для клубов), ОГРН, сертификаты, гарантийное письмо |
| **Перевозки/такси-агрегаторы, доставка лекарств агрегаторами** | Для агрегаторов лекарств — договор с аптекой на дистанционную продажу или ссылка на оферту с подтверждением присоединения |
| **Брендированная продукция** (Nike, Adidas, Reebok, Ray Ban, Apple) | ОГРН/ОГРНИП, гарантийное письмо об оригинальности товара |
| **Использование изображений людей** | Знаменитости — письменное согласие; родственники/знакомые — согласие + гарантийное письмо; фотобанки — гарантийное письмо |
| **Интеллектуальная собственность** (музыка, кино, книги, ПО) | Лицензионный договор / договор отчуждения прав / договор с РАО-ВОИС / для авторов — паспорт + гарантийное письмо; для ПО — те же варианты либо свидетельство регистрации программы ЭВМ |

Если категория не покрыта таблицей — свериться с полным списком `documents/required_documents`: авточасти (катализаторы, номера, техосмотр), туризм, гостиничный бизнес, лазертаг/пейнтбол, охота, рыбалка, дезинфекция/дезинсекция, детектив, майнинг-фермы, платёжные системы, доверительное управление, медиация, арбитраж, детское питание, ЛФК, массаж (лицензируется не всегда — зависит от позиционирования, см. `required_documents#massage`), маски/респираторы, оптика/линзы, остеопатия, подология, контрацепция/лубриканты, спортивное питание.

## 4. Требования к тексту

Источник: `documents/moderation` п.2.1–2.11, `documents/faq_moderation`.

**Запрещённые формулировки и приёмы:**
- Превосходная степень без пруфа: «лучший», «номер 1», «самый», «крупнейший», «главный», «первый» — допустимо только с документом от независимой стороны (исследование/рейтинг), опубликованным на сайте и указанным в креативе (п.2.8.1)
- Некорректные сравнения с товарами/услугами других компаний (п.2.8) и любые упоминания конкурентов по названию/логотипу (п.2.6)
- «100%», «гарантированно», необоснованные гарантии результата, быстрого заработка, исцеления (п.2.7.1)
- Кликбейт и принуждение к действию: «Осторожно», «Я жду», «Жми», «Шок», «Сенсация», «Хит» — усилители без смысловой нагрузки под запретом (п.2.1.1, 2.7.2)
- Текст от первого лица о результате: «Я похудела на 40 кг…», «Я стал миллионером…» — запрещено. Допустимо, только если это про конкретную персональную услугу («Сошью тебе платье на заказ») (п.2.7.3)
- Обращение по точному возрасту старше 19 лет («Тебе 27?», «Родился в 1983?») — для детей и людей до 18 включительно возраст называть можно
- Точная дата рождения («День рождения 1 марта?») — можно только неточно и в контексте акции для именинников
- Персональные данные (имя как обращение, диагнозы, сексуальная ориентация, финансовое положение) и догадки по подпискам («Вы мама первоклассника?»)
- Микрогео для не-локального бизнеса («Живёшь в Ленинском районе?» — про онлайн-марафон); для реально локального бизнеса (фитнес-клуб в этом районе) — можно
- Автоматические редиректы (js/meta), сокращатели ссылок (п.2.10)
- Ненормативная лексика, дискриминационные высказывания по полу/расе/религии/возрасту и т.п. (п.2.11)
- Утверждения/предположения о наличии у читателя болезни («У вас простуда») — можно перечислять симптомы, но не диагностировать
- Незакрытые условия «бесплатно» при наличии скрытых условий

**Технические требования к тексту (п.2.1.1–2.1.3):**
- Грамотный русский язык без опечаток и обрывов слов на границе лимита символов; текст объявления не может быть продолжением заголовка
- Не более одного восклицательного/иного знака препинания подряд, никаких скобок-смайликов «:)», «((», разрядки «б у к в а м и»
- КАПС запрещён, кроме общеизвестных аббревиатур и зарегистрированных товарных знаков (для последних — прислать свидетельство)
- Иностранные слова допустимы только как общепринятые аббревиатуры (USB, HDMI) или товарные знаки; иначе объявление отклонят — переписать на русском или дать транслитерацию
- Контакты (телефон/email) в основном тексте — не по правилам «эмодзи/пунктуации» напрямую, но такие поля лучше выносить в форму/«О компании», а не смешивать с рекламным текстом

**Эмодзи (п.2.1.1, faq_moderation):**
- До **5 эмодзи** из разрешённого unicode-списка в тексте/видео/изображении
- Запрещены полностью в: заголовках (включая заголовки карусели), названии сообщества, тексте у кнопки, поле юридической информации
- Для рекламы каналов в **Дзене — эмодзи запрещены полностью** (п.1.4)
- Текстовые смайлы «:)», «((» не считаются эмодзи и запрещены всегда

## 5. Требования к визуалу

Источник: `documents/moderation` п.2.2.1–2.2.8, `documents/faq_moderation`.

- Текст на изображении/видео — **не более 20% площади**; проверка через инструмент [Робби](http://robbi.ai). Это касается и логотипа/иконки после автокадрирования под разные форматы размещения
- Изображение — высокого качества, без размытия, некачественной обрезки, доморощенной домашней съёмки, тёмных фото и захламлённого фона
- Нельзя оставлять белые/чёрные/цветные поля по краям картинки (типично при неверном соотношении сторон)
- Запрещены агрессивные/неоновые цветовые сочетания и раздражающие надписи на ярком фоне
- Запрещены грубые склейки/коллажи из большого числа фото — **исключение**: классифайды и маркетплейсы, для которых склейка допустима
- Откровенный/сексуальный контент: обнажение, вызывающая одежда, провокационные позы, «сексуальные метафоры» (разрезанная клубника и т.п.) — запрещено
- **Алкоголь и табак на изображении/видео — запрещены в любом виде**, включая сувенирные товары в форме бутылок/сигар; исключение — трейлеры фильмов при таргетинге 18+ и возрастной маркировке
- Пугающий/шокирующий контент: травмы, увечья, катастрофы, кровь — запрещено, фокус на негативных деталях недопустим
- **Изображения денежных купюр, монет и слитков — запрещены** (п.2.2.5)
- Для лицензируемых медицинских/косметологических процедур — запрещено сравнение «до/после» и видеодемонстрация самой процедуры. Коллаж «до/после» допустим только для **не**лицензируемых процедур (перманентный макияж, маникюр, фейслифтинг) — при этом фото «до» не должно вызывать отвращение
- Лица людей (в т.ч. публичных — музыканты, спортсмены, блогеры) — только при документальном согласии (см. таблицу раздела 3); при использовании фото лиц, признанных иноагентами, — обязателен дисклеймер об этом статусе
- Логотипы конкурирующих брендов запрещены (п.2.6); логотип и фирменный стиль самой VK — запрещены к имитации, кроме согласованных партнёрств; логотип VK допустим только как ссылка на сообщество ВК или в QR-коде
- Имитация интерфейса — фейковые кнопки, чекбоксы, крестики закрытия, элементы «системного уведомления/ошибки» — запрещена

## 7. Обязательный таргетинг 18+ (настройка аудитории, не только текст)

Источник: `documents/moderation` п.4.1, `documents/faq_moderation`.

Обязательно выставлять возраст «от 18» в блоке «Демография» + «Возрастная маркировка» 18+ для:
- медицинской техники и медицинских изделий;
- аптек, лекарств;
- ветуслуг и ветеринарных аптек;
- финансовых услуг;
- лотерей и любых стимулирующих мероприятий с призовым фондом;
- сервисов знакомств;
- энергетиков — если в регионе показа их продажа лицам младше 18 запрещена.

**Важно:** это отдельная настройка от текстовой возрастной маркировки на самом креативе — если на картинке стоит «18+», такая же маркировка должна совпадать с настройкой кампании (иначе — расхождение и отказ). Аудиторию по возрасту при этом можно сузить и дальше (например, 20–50 лет) — главное, чтобы нижняя граница не опускалась ниже 18.

Азартные игры (кроме покера) и вейпы/электронные сигареты — это **не** «18+», это **полный запрет**, таргетингом не обойти.

## 8. Поле «О компании» (юридическая информация)

Источник: `documents/faq_moderation` («Информация о компании», «Данные интернет-магазина»).

- Поле предназначено **исключительно** под юридические данные: название компании/ИП, адрес с индексом, ОГРН/ОГРНИП/ИНН. Никакой другой текст туда класть нельзя.

- Альтернатива для интернет-магазина: указать те же сведения о продавце на самом баннере/видео, а для карусели — на первом слайде или на всех слайдах (не обязательно только в поле).

## 9. Спец-правила по форматам активностей

### Конкурсы, розыгрыши, лотереи
Источник: `documents/moderation` п.1.2, `documents/faq_moderation`, `documents/required_documents#lotto`.
- В рекламе стимулирующего мероприятия должны быть указаны: сроки проведения, источник информации об организаторе, правила проведения, количество призов, сроки/место/порядок их получения.
- Сроки можно **не указывать**, если это скидка/акция/распродажа/подарок за покупку/промокод — то есть когда в тексте нет прямых слов «конкурс», «розыгрыш», «лотерея».
- Если мероприятие в группе ВКонтакте — полные условия можно разместить в закреплённом посте группы (соответствие [Правилам проведения конкурсов ВКонтакте](https://vk.com/@adminsclub-pravila-soobschestv?anchor=konkursy-i-aktsii)), тогда в самом объявлении сроки не обязательны.
- Если мероприятие на другой площадке — сроки указываются в тексте, на креативе или в поле «О рекламодателе».
- Для лотерей (не просто розыгрышей) — нужны документы: уведомление о лотерее в госорган или разрешение на её проведение (см. таблицу раздела 3). Обязателен таргетинг 18+.

### Банкротство и списание долгов
Источник: `documents/faq_moderation`.
- Реклама должна явно позиционироваться как **юридические/консультационные услуги**, а не как обещание результата.
- **Запрещены** формулировки: «Долг можно списать», «Спишем долг», «Ваш долг более 300 тыс.? Спишем», «Списали 400 тыс. долга», «Помогли Ивановой И.И. списать долг», «Более 2 млрд долгов списано» — всё это вводит в заблуждение обещанием гарантированного результата.
- **Разрешены**: «Консультация по вопросам банкротства», «Сопровождение по процедуре банкротства».
- Запрещены фото «счастливых людей, избавившихся от долга» и фото сотрудников ФССП/госорганов (в т.ч. на лендинге).
- Обязателен дисклеймер (раздел 6) + недопустима идентификация пользователя как должника в самом объявлении.

### Реклама личных страниц ВКонтакте
Источник: `documents/moderation` п.1.3, `documents/faq_moderation`.
- Разрешено, только если страница оформлена как **реальный профиль**: реальные имя+фамилия в названии, реальное фото пользователя на аватарке.
- Бизнес-элементы (логотип компании, прайс, услуги, акции) в шапке/постах допустимы — сама структура страницы должна быть личной.
- **Запрещено** рекламировать: страницы, зарегистрированные от чужого имени; страницы на несколько человек («Маша и Петя Ивановы») или юрлицо; профили, где вместо имени — название организации; аватарки с логотипом компании вместо фото человека.
- Если нужно продвигать организацию — использовать сайт, сообщество ВК или группу в Одноклассниках, а не личную страницу.

### Криптовалюта / ЦФА
Источник: `documents/moderation` п.4.7.
- **Запрещена** покупка/продажа товаров и услуг (в т.ч. цифровых, NFT) **за криптовалюту** — крипта не может фигурировать как средство платежа на территории РФ.
- Реклама **не должна**: гарантировать быстрый заработок, обещать успешные сделки или рост доходности, утверждать безрисковость операций с криптовалютой.
- Реклама не должна содержать признаков финансовой пирамиды (выплата дохода за счёт вновь привлечённых средств).
- Сама реклама криптоуслуг/бирж как таковая не под полным запретом — регулируется этими ограничениями по формулировкам, а не списком «нельзя вообще».

### Сервисы знакомств
Источник: `documents/moderation` п.3, п.4.5, `documents/faq_moderation`.
- Секс-подтекст в позиционировании («знакомства для интима», «на одну ночь») — под полным запретом.
- В изображениях нельзя акцентировать оголённые части тела и провокационные позы.
- Текст не должен вводить в заблуждение относительно намерений конкретных людей: «Найдите свою половинку» — можно, «Лёгкие знакомства», «Ищу мужчину постарше» — нельзя.
- Нельзя использовать имена людей на фото в объявлении («Жанна. Встречусь сегодня»).
- Объект рекламирования должен иметь: описание целей, правила и пользовательское соглашение, контакты поддержки, бесплатный доступ наравне с платными опциями (без обязательного членского взноса), без SMS-оплаты/скрытых подписок.
- Обязателен таргетинг 18+ (раздел 7). VK вправе отказать в размещении такой рекламы по своему усмотрению даже при формальном соответствии правилам.

### Финансовые услуги (кредиты/займы/ипотека, детальный расклад)
Источник: `documents/faq_moderation`.
- На сайте, куда ведёт реклама, должны быть перечислены: ставка, сроки (мин/макс/пример), первый взнос/платежи, возраст заёмщика, доп. комиссии, минимальные и максимальные значения ПСК, необходимость страхования, прочие расходы.
- В самом объявлении: ссылка «Подробные условия на сайте: …», дисклеймер (раздел 6), диапазон ПСК шрифтом того же размера **до** указания ставки, наименование/ФИО оказывающего услугу лица.

## 10. Сроки/статусы модерации (кратко)

- Точных часовых нормативов VK публично не раскрывает — учитывать модерацию как «дополнительное время» при планировании старта, особенно для категорий с документами.
- Документы на вертикаль отправляются один раз при первом запуске, дальше повторно не требуются, если состав рекламируемых товаров/услуг не меняется.
- Любая правка текста/изображения/ссылки/настроек демографии = повторная отправка на проверку.
- После одобрения объявление всё равно может быть отклонено при **постмодерации** — правило действует бессрочно, а не только на старте.
- Для рекламы событий/акций с конкретной датой — объявление должно крутиться **до или во время** самого события; создавать кампанию стоит заранее с запасом на модерацию.
- Отказ в размещении или отклонение объявления VK вправе делать **без объяснения причин** (п.5, п.6) — при отказе стоит в первую очередь сверяться с этим чек-листом, а не ждать развёрнутого фидбека.
