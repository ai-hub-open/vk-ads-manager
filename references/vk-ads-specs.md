# VK Ads — спецификации форматов, лимиты, требования модерации

> Все числовые лимиты сверены с официальной справкой VK Рекламы (ads.vk.com/help). У каждого блока указан слаг-источник. При обновлении — перепроверять по нему, а не по памяти.

## Цели рекламных кампаний (campaign objectives)

В VK Реклама цели задаются на уровне кампании. Алгоритм оптимизируется именно под выбранную цель — смешивать в одной кампании задачи нельзя.

| Цель | Что оптимизируется | Когда выбирать |
|---|---|---|
| Сайт (конверсии) | Целевые события на сайте (через пиксель) | Главная цель для бизнеса с лендингом. Нужен пиксель + 50+ событий/неделю. |
| Сайт (трафик) | Клики по объявлению | Если пиксель не настроен / мало событий. Менее эффективно. |
| Лиды (форма VK) | Заявки через встроенную форму VK | Когда нет лендинга или нужны лиды с мобайла без перехода. |
| Сообщество (подписчики) | Подписки на VK-сообщество | Для построения базы / постоянного контакта. |
| Сообщество (вовлечение) | Лайки/комменты/репосты | Для прогрева холодной аудитории. |
| Приложение | Установки/события в приложении | Для мобильных приложений. Требует добавленного и подтверждённого приложения + трекера (см. app-promotion). |
| Каталог товаров | Просмотры/в корзину/покупки/избранное | Для e-commerce с фидом. Типы: привлечение клиентов / динамический ретаргетинг. Оптимизация на покупку — после подключения пикселя. Источник: general/ecomm/feed_campaign. |
| Видео-просмотры | Досмотры видео | Для brand awareness через короткое видео. |
| Магазин (визиты) | Геолокационные клики | Для оффлайн-точек. |

**Главное правило:** одна кампания = одна цель. Если нужны и подписчики, и лиды — это две кампании. **Цель и рекламируемый объект нельзя изменить после запуска** — потребуется новая кампания (источник: general/start/creating).

## Стратегии ставок

| Стратегия | Как работает | Когда использовать |
|---|---|---|
| **Минимальная цена** (рекомендуется VK) | Указываешь бюджет; алгоритм даёт максимум результатов в его пределах | Дефолт. Для всех новых кампаний. Хорошо работает после 50+ конверсий. |
| **Предельная цена** | Указываешь бюджет + макс. цену конверсии | Когда уже знаешь свой целевой CPL и нужно его не превышать. Не использовать на старте — алгоритм будет душить открутку. |

**Бюджет** задаётся на уровне **кампании** (не группы) — алгоритм сам распределяет между группами. Можно дополнительно ограничить дневной/общий бюджет.

**Минимальный бюджет (источник: general/start/budget_limits):** минимальное значение дневного и общего лимита — **300 ₽**. Для продвижения в **Дзене — 10 000 ₽**. Бюджет ниже минимума не даст запустить кампанию.

**Минимум для теста (рекомендация):** 30-50 тыс ₽ / 14 дней. Меньше — алгоритм не выходит из обучения (нужно 50+ событий целевого действия в неделю).

**Лимит объявлений (источник: general/start/ad_limits):** общий лимит — 300 объявлений для новых аккаунтов, растёт с тратами (+1 баннер за каждые 150 ₽ при балансе/тратах свыше 3000 ₽). Дневной лимит — 200 объявлений в сутки. Это лимит на **объявления**, не на кампании.

## Форматы объявлений и лимиты

> Ключевой источник лимитов текста/медиа перформанс-объявлений: general/start/creating. Лимиты заголовка зависят от рекламируемого объекта.

### Универсальная запись (Universal)
**Главный перформанс-формат.** Использовать в большинстве перформанс-задач.

| Параметр | Лимит |
|---|---|
| Заголовок | **сайт — до 25 знаков**; приложение/сообщество/лид-форма/мини-приложение — до 40 знаков |
| Текст | до 16 384 знаков (с 2026), но первые 200-220 критичны (выше «Показать ещё») |
| Текст рядом с кнопкой | до 30 знаков |
| Поле «О компании» (юр.инфо) | до 115 знаков |
| Изображения | до 6 в карусели; **мин. 600×600 px (1:1)**, 1080×607 px (16:9), 1080×1350 px (4:5); рекоменд. 1080×1080 для 1:1 |
| Видео | **mp4/mpeg/avi/mov, до 90 МБ**, до 60 сек, мин. 600×360 px, 16:9 / 1:1 / 9:16 |
| CTA-кнопка | из списка VK (см. ниже) |

> Внимание: лимиты выше — для **перформанс**-объявлений (цели «Целевые действия»). Для **медийной видеорекламы** (охватные CPM-кампании «Узнаваемость и охват») лимиты другие — длительность до 180–300 сек, свои размеры. См. branding-formats (раздел «Форматы и площадки»).

### Карусель (Carousel)

| Параметр | Лимит |
|---|---|
| Карточек | **3-6** (карусель сайта, источник general/sites/sites). Отдельный формат «Галерея медиафайлов» — 2-10 файлов, **без текста и кнопки** |
| Заголовок карточки | сайт — до 25 знаков; приложение — до 25; сообщество/лид-форма — до 40 |
| Описание карточки (длинное, для сайтов) | до 2000 знаков |
| Описание карточки (короткое) | до 90 знаков |
| Описание слайда (для приложений) | до 32 знаков (источник general/apps/app_campaign) |
| Изображение карточки | мин. 600×600 px (1:1) |
| CTA на карточку | да, разная для каждой |

### Видео (перформанс)

| Параметр | Лимит |
|---|---|
| Длительность | до 60 сек (рекомендуется 15-30) |
| Размер файла | **до 90 МБ** |
| Формат | mp4 / mpeg / avi / mov |
| Соотношение сторон | 16:9 (горизонтальное), 1:1 (квадрат), 9:16 (вертикальное — для VK Клипов) |
| Минимальное разрешение | **600×360 px** |
| Заголовок | сайт — до 25 знаков; приложение/сообщество/лид-форма — до 40 |
| Текст | до 2000 знаков для сайтов |

**Вертикальное видео 9:16 — отдельный приоритет.** Растёт быстрее всего, особенно у P3-персон (блогеры/креаторы). Если есть возможность снять — снимай.

### Лид-форма VK (Lead Form)

| Параметр | Лимит |
|---|---|
| Заголовок | до 50 знаков |
| Описание | компактная форма — до 35 знаков; тип «больше текста» — до 350 знаков |
| Поля формы | имя/телефон по умолчанию, доп. поля добавляются кнопкой; саму форму собирают в кабинете (API создаёт только объявление-обёртку) |
| Согласие на обработку ПДн | обязательно (текст + чекбокс) |
| Спасибо-экран | кастомный |

Источник лимитов: general/lead_forms/lead_forms. Используется когда **нет лендинга** или нужна **мобильная конверсия без перехода**. Forms работают только с целью «Лиды». Детали конструктора, интеграции CRM и уведомления — см. lead-forms (если файл добавлен).

### Коллаж (Collage)

Менее популярный, но иногда полезный. Лимиты:
- Заголовок: сайт до 25, приложение/сообщество/лид-форма до 40
- Длинное описание (сайты) до 2000
- Короткое описание до 90
- Для приложений «Галерея медиафайлов» — коллаж/слайдер **без текста и кнопки**, 2–10 медиафайлов (источник general/apps/app_campaign)

### Маркет-платформа (платный посев)

Размещение в сообществах VK через биржу. Цены договорные с админами, маркировка ОРД обязательна.

## Требования модерации (что точно не пройдёт)

> Списки сверены с documents/moderation, documents/required_documents, documents/faq_moderation. Расширенный разбор правил по вертикалям — см. moderation-rules (если файл добавлен).

### Запрещённые тематики (полный запрет)
- Алкоголь, спиртосодержащая продукция (полный запрет, **без B2B-исключений**)
- Табак, вейпы, электронные сигареты, кальяны
- Наркотики, оружие
- Азартные игры: казино, тотализаторы, ставки на риске/пари. **Исключение — только покер** как интеллектуально-коммерческая игра
- Сетевой маркетинг (MLM) с обещанием дохода
- Услуги магов/гадалок/экстрасенсов

> Источник: documents/moderation п.3.

### Под лицензию / по документам (загрузить документы перед запуском)
- Медицина, медтехника, медизделия, лекарства, аптеки
- Образование (если выдаёте сертификаты/дипломы)
- БАДы
- Финансовые услуги, кредиты/займы, страхование
- **Форекс-дилеры, бинарные опционы** — при наличии лицензии (дилерская/брокерская/решение о выпуске ЦФА/лицензия профучастника)
- **Криптовалюта/ЦФА** — регулируется, а не запрещена: нельзя как платёжное средство, нельзя гарантировать доходность; допускается по правилам
- Застройщики/долевое строительство, лотереи, ювелирные изделия и др. — полный перечень в documents/required_documents (~40 вертикалей)
- Перевозки

> Крипта, форекс и бинарные опционы — **НЕ полный запрет**: допускаются при наличии лицензий/по правилам. Источник: documents/moderation п.4.7, documents/required_documents.

### Запрещённые формулировки в тексте
- «100%», «гарантированно», «гарантия результата» (без пруфа)
- «Лучший», «единственный», «самый», «номер 1» (без пруфа от независимого источника)
- «Только сегодня», «осталось N мест» (если это неправда — легальную срочность даёт макрос `{{countdown}}`, см. ad-copywriting)
- «Бесплатно» (если есть скрытые условия)
- Сравнения с конкурентами по имени
- Текст **от первого лица** о результате («Я похудела на 40 кг…») — запрещён, кроме конкретной персональной услуги
- Обращение **по точному возрасту / дате рождения / микрогео** («Тебе 27?», «Живёшь в Ленинском районе?») для не-локального бизнеса

> Источник: documents/moderation п.2.7.3, 2.9, documents/faq_moderation.

### Запрещённые формы текста
- КАПС (целые слова прописными — нельзя; начало предложения — можно)
- Больше одного восклицательного знака подряд
- **Эмодзи: до 5 в тексте объявления**; запрещены в заголовках (в т.ч. каруселей), названии сообществ, юр.поле «О компании» и в тексте рядом с кнопкой. Для объявлений **Дзена эмодзи запрещены полностью** (источник: documents/moderation п.2.1.1, documents/faq_moderation)
- Грамматические ошибки и опечатки
- Контактные данные (телефон, email) в основном тексте — только в форме или в поле «О компании»

### Запрещённый визуал
- Логотипы конкурирующих брендов
- Лица знаменитостей без согласия
- 18+ контент без возрастной плашки
- Шок-контент (травмы, кровь, ужасы)
- Реклама в стиле «системного уведомления» или «ошибки» — обман
- **Изображения денежных купюр, монет, слитков** — запрещены
- Текст должен занимать **не более ~20% площади изображения** (частая причина отказа)

> Источник: documents/moderation п.2.2.1, 2.2.5.

### Дисклеймеры и обязательные требования
- **Таргетинг 18+** (настройка возраста аудитории, не только текст) — медтехника/медизделия, аптеки/лекарства, ветуслуги/аптеки, финуслуги, лотереи, знакомства. Азарт и вейпы/электронные сигареты — **запрещены полностью**, а не «18+». Источник: documents/faq_moderation, documents/moderation п.4.1
- **«Имеются противопоказания, проконсультируйтесь со специалистом»** — медицина и БАДы. Размер дисклеймера: медицина/косметология ≥5% площади, БАД ≥10%
- **Финансовый дисклеймер** для кредитов/займов: «Изучите все условия кредита (займа) на сайте…»; при указании ставки — диапазон ПСК тем же шрифтом; ≥10% площади
- **Поле «О компании»** («Реклама. Рекламодатель: …») обязательно **ТОЛЬКО** при рекламе товаров с онлайн-продажей. Для услуг/офлайн-магазина поле оставить **ПУСТЫМ** (другой текст не допускается). Источник: documents/faq_moderation

## ОРД-маркировка

С 1 сентября 2022 вся интернет-реклама в РФ подлежит маркировке через ОРД (оператор рекламных данных) → ЕРИР (единый реестр интернет-рекламы).

**В VK Реклама — автомаркировка.** Что нужно сделать:
1. В кабинете ads.vk.ru → Настройки → ОРД → ввести юридические данные (для физ.лица — ФИО, ИНН 12 знаков; для ИП/ООО — реквизиты, ИНН юрлица 10 знаков)
2. Подключить ОРД VK (без доп. платы для пользователей VK Реклама)
3. При создании кампании галочка «Передать данные в ОРД» включена по умолчанию
4. Поле «О компании» (115 знаков) заполняется юр.информацией — она войдёт в плашку «Реклама. Рекламодатель: ...»
5. ERID (токен) автоматически присваивается каждому креативу при модерации, проставляется на финальном баннере
6. Ежемесячно VK ОРД сам передаёт данные в ЕРИР

**Что НЕ требуется** прямому рекламодателю через VK Реклама:
- Самостоятельно регистрироваться в ОРД
- Получать ERID руками
- Отчитываться в ЕРИР (VK передаёт данные сам)

**ВАЖНО для агентств:** агентство обязано **ежемесячно передавать акты по своим клиентам с 15 по 30 число следующего месяца** (вкладка «Отчёты для ОРД»). Это НЕ снимается автоматикой VK. Источник: ord/ord_agency_report. Подробный агентский флоу ОРД — см. ord-agency (если файл добавлен).

**Что требуется ДОПОЛНИТЕЛЬНО**, если:
- Платный посев через маркет-платформу — ОРД нужно настроить отдельно (часто решается через ОРД-сервисы типа Лидгет, OneSpot)
- Использование рекламы на стороне (баннеры на партнёрах, не в VK кабинете) — отдельная маркировка

**Сбор на рекламу 3% (ФЗ №479-ФЗ, с 01.04.2025):** уже действует. Рекламодателям сумма передаётся автоматически; для посреднических (агентских) договоров в актах нужно указывать сумму без НДС, ставку НДС и вознаграждение посредника. Использование ОРД VK в рамках рекламных систем — без дополнительной платы. Источник: ord/tax, ord/ord_meaning.

## Чек-лист перед отправкой на модерацию

- [ ] Заголовок ≤ 25 знаков (сайт) / ≤ 40 (приложение/сообщество/лид-форма)
- [ ] Текст без КАПС / двойных «!»
- [ ] Нет «100%», «лучший», «гарантия» без пруфа; нет текста от первого лица / обращения по возрасту
- [ ] Эмодзи ≤ 5 в тексте, нет в заголовке/у кнопки/названии сообщества/юр.поле (в Дзене — 0)
- [ ] Поле «О компании» заполнено ТОЛЬКО для товаров с онлайн-продажей; для услуг/офлайн — пустое
- [ ] ОРД-маркировка включена (для агентства — не забыть ежемесячные акты)
- [ ] CTA-кнопка выбрана из списка
- [ ] Изображения: мин. 600×600 (1:1); видео ≤ 90 МБ; текст ≤ 20% площади картинки
- [ ] Лицензии/документы загружены (если категория требует)
- [ ] Дисклеймеры на месте нужного размера (если категория требует)
- [ ] Пиксель установлен (если цель — конверсии)
- [ ] Лендинг доступен, форма работает
