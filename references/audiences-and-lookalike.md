# VK Ads — аудитории, пиксель, lookalike, CRM

Кастомные аудитории — главное конкурентное преимущество в VK Реклама. Это про работу с собственными данными.

## Типы кастомных аудиторий

### 1. Пиксель + события сайта
Главный источник для конверсионной оптимизации и LAL.

**Что нужно:**
1. Установить пиксель VK Ads на сайт (`scripts/vk_pixel_helper.py` сгенерит код)
2. Настроить события: `page_view`, `lead`, `purchase`, `add_to_cart`, `registration`, `view_content` и кастомные
3. Дождаться накопления данных: минимум 1000 уникальных юзеров для LAL

**Что можно сделать дальше:**
- Ретаргетинг по любому событию (например, «добавил в корзину, но не купил за последние 7 дней»)
- LAL по любому событию (например, LAL 1% от тех, кто купил)
- Исключения (например, показывать рекламу всем, кроме покупателей)

### 2. CRM-загрузки (списки)
Загрузка собственной базы клиентов в кабинет VK Реклама.

**Что нужно:**
1. Подготовить CSV. Идентификаторы: phone (**только цифры без «+» и разделителей: `79011234567`**), email, vk, ok, vid, gaid, idfa. Единый список — колонки `phone,email,ok,vk,vid,gaid,idfa`, файл до 128 МБ, UTF-8. Хэширование: MD5 (телефоны/email; для email матчинг хуже), SHA-256 (только телефоны). Источник: features/audiences_lists/user_lists
2. **Минимум 100 уникальных записей** для загрузки списка (порог 1000 — это для построения look-alike, а не для загрузки)
3. Загрузить в Кабинет → Аудитории → Создать → По данным CRM
4. Дождаться обработки (1-24 часа)

**Когда использовать:**
- Существующая база клиентов → LAL для масштабирования
- База подписчиков рассылки → ретаргетинг с горячим оффером
- База тех, кто не дочистил → реактивация
- База неоплативших / отказников → точечный ретаргет с другим оффером

**Качество базы критично:** 1000 случайных контактов дадут мусорный LAL. 1000 платных клиентов с LTV > 5000 ₽ — золото.

### 3. Аудитории сообществ
Подписчики конкретных сообществ VK.

**Два варианта:**
1. **Сообщества конкурентов / тематические** — VK позволяет таргетить на подписчиков любого открытого сообщества. Ищется в настройках таргетинга по ID или ссылке. Лимит — **до 300 сообществ ВК/ОК** в одну аудиторию; таргетинг возможен только на сообщества с более чем 50 подписчиков (источник: features/audiences_lists/audiences).
2. **Собственные сообщества** — таргет на собственных подписчиков (через ID сообщества). Хорошо работает для апсейла и для смежных продуктов.

### 4. Lookalike (LAL)
Похожая аудитория на основе исходной.

**Как работает:**
- VK анализирует профили исходной аудитории (демография, интересы, поведение в экосистеме)
- Находит похожих пользователей в общей базе VK
- Выдаёт «LAL 1%» (≈1% от всех пользователей VK ~ 1-2 миллиона) — самые похожие

**Шкала точности:**
- LAL 1% — самые похожие, маленький охват (~1-2M по РФ), но самое высокое качество
- LAL 2-3% — среднее качество, средний охват
- LAL 4-5% — низкое качество, большой охват

**Минимум для построения (источник: features/audiences_lists/look_alike):** зависит от источника — **1000 человек** для списков пользователей / данных счётчика Top.Mail.Ru / событий мобильных приложений; **3000 человек** — для событий в рекламных кампаниях.

**Стратегия каскадного масштабирования:**
1. Начать с LAL 1% от лучшей исходной (платные клиенты / посетители страницы спасибо)
2. Когда LAL 1% выдохся (CPL начал расти) → подключить LAL 2-3%
3. Параллельно расширять — LAL 4-5%
4. VK обновляет look-alike **автоматически 1 раз в день** (источник: features/audiences_lists/look_alike). Ручная работа — дозаливать свежие конверсии в *исходную* аудиторию, а не пересобирать LAL

### 5. Ключевые фразы (key phrases)
То что пользователь искал в VK Поиске / Маркете за выбранный период — **от 1 до 30 дней, по умолчанию 12** (источник: features/audiences_lists/audiences).

**Когда использовать:**
- Горячий спрос с конкретными запросами
- Аналог поискового таргетинга в Директе, но в VK
- В связке с интересами

**Особенности:**
- Лимит ~200 фраз в одну аудиторию
- Можно с операторами (точное совпадение, словоформы)
- Работают хуже соцдем+интересы, потому что выборка маленькая (не все ищут именно через VK)

### 6. Каталог (для e-commerce)
Аудитория на основе действий в каталоге товаров (просмотры конкретных карточек). Требует загруженного каталога/фида (Центр коммерции) и настроенных событий динамического ретаргетинга с параметром `product_id`. Каталог можно создать из фида по ссылке, из товаров сообщества ВКонтакте или из маркетплейса — не только «VK Маркет». Подробнее — см. ecommerce-catalogs (если файл добавлен).

### 7. Расширение аудитории (expand_audiences) [MCP]
Нативный переключатель уровня группы объявлений: VK сам подбирает похожих пользователей на основе источника (сайт/сообщество/лид-форма/приложение). Более простая альтернатива ручному LAL. Обновление: раз в 4 дня (сайт/приложение/лид-форма), раз в неделю (сообщества); нужен порог ≥1000 распознанных пользователей. Источник: features/audiences_lists/expand_audiences. При заливе через API проверить наличие соответствующего поля группы и включать по умолчанию для холодных сегментов.

## Пиксель VK Ads — пошагово

### Установка
1. Кабинет → Сайты → Создать пиксель
2. Скопировать код (JS-сниппет)
3. Вставить в `<head>` сайта на ВСЕХ страницах
4. Проверить в кабинете «Активность пикселя»

### Базовые события (минимум)
- `page_view` — стреляет автоматически при загрузке
- `lead` — нажатие кнопки заявки, отправка формы
- `purchase` — успешная оплата
- `registration` — регистрация в сервисе
- `view_content` — просмотр карточки товара / страницы продукта

### Передача параметров с событиями
```javascript
// Пиксель VK Рекламы работает через top.mail.ru (_tmr), не через старый VK.Goal
_tmr.push({ type: 'reachGoal', id: PIXEL_ID, goal: 'lead', value: 5000, params: { product: 'aismm_pro_starter' } });
```
Параметры — для сегментации (например, LAL по покупкам > 5000 ₽ vs всех покупок). Для **динамического ретаргетинга каталога** обязательны события `viewProduct` / `addToCart` / `purchase` с параметром `product_id` — без него товарная реклама не работает (см. ecommerce-catalogs).

### Альтернативы JS-пикселю
- **Conversion API** — серверная передача событий (для приватности / для блокировщиков)
- **Tag Manager** через GTM (рекомендуется для не-разработчиков)

### Чек-лист готовности пикселя
- [ ] Пиксель установлен на всех страницах сайта
- [ ] Активность в кабинете «зелёная» (>10 событий/час)
- [ ] Настроены минимум 3 события: `page_view`, `lead`, `purchase`
- [ ] Цели в кабинете VK Реклама замаплены на события пикселя
- [ ] Проверено: событие срабатывает после реального действия (открыть DevTools, посмотреть Network запросы к `top-fwz1.mail.ru/counter`)

## Архитектура аудиторий — рекомендации

### Минимальный набор на старте (для конверсионной кампании)
1. **Hot:** LAL 1% от посетителей лендинга (нужен пиксель + 1000+ юзеров)
2. **Warm:** Интерес «<категория>» + сужение по соцдему персон
3. **Cold:** Соцдем + 1 широкий интерес

3 группы × 3-5 креативов = 9-15 объявлений. Этого достаточно для теста.

### Полный набор (для зрелого бизнеса с CRM-базой)
1. **H1:** LAL 1% от платных клиентов (CRM)
2. **H2:** Ретаргет 7 дней (посетители, не купили)
3. **H3:** Ретаргет «добавил в корзину, не купил» (3 дня)
4. **W1:** LAL 2-3% от платных клиентов
5. **W2:** Подписчики сообществ конкурентов (3-5 крупнейших)
6. **W3:** Интересы по тематике + соцдем персон
7. **C1:** LAL 4-5% от платных клиентов
8. **C2:** Широкий соцдем + 1 широкий интерес
9. **C3:** Ключевые фразы (если применимо)

9 групп × 3-5 креативов = 27-45 объявлений. Сложнее в управлении, но даёт максимум.

### Антипаттерны
- **LAL от всех посетителей сайта без сегментации** — мусор. Делать LAL только от качественной выборки (купили, дошли до checkout, провели > 1 минуты).
- **Пересекающиеся аудитории без исключений** — алгоритм будет переплачивать за одного и того же юзера. Всегда: warm = LAL — hot, cold = широкое — warm — hot.
- **CRM-список со старыми контактами** (> 2 лет) — низкий матчинг, плохой LAL.
- **LAL от слишком узкой исходной** (< 1000 совпавших) — VK не построит надёжный профиль.

## Lookalike — глубже

### Что VK действительно анализирует
- Поведение в экосистеме (что лайкает, что смотрит, в каких сообществах)
- Социальный граф (друзья, кто чем интересуется)
- Покупательскую активность (VK Маркет)
- Демографию (заявленную и предсказанную)
- Историю поиска внутри VK
- Технические сигналы (с какого устройства, как часто заходит)

### Что VK НЕ анализирует
- Поведение пользователя ВНЕ VK (если не настроен пиксель и нет события)
- Phone/email напрямую (используются только для матчинга)
- Контент личных сообщений

### Качество LAL: что улучшит
- **Источник** — лучший вариант: те, кто купил несколько раз / с высоким чеком / с долгим LTV
- **Свежесть** — VK пересчитывает LAL автоматически ежедневно; свежесть повышаешь дозаливом новых конверсий в *исходную* аудиторию
- **Объём исходной** — лучше 5000-10000 совпавших, не 1000
- **Чистота** — фильтровать аномальные клики, ботов

### Сравнение качества по источнику (от лучшего)
1. Платные клиенты с высоким LTV → LAL 1%
2. Дошли до checkout, не купили (горячие интенты) → LAL 1-2%
3. Зарегистрировались (Free / триал) → LAL 1-2%
4. Подписчики сообщества с высокой активностью → LAL 2-3%
5. Посетители сайта > 1 минуты → LAL 2-3%
6. Все посетители сайта → LAL 3-5%
