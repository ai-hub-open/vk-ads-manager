# VK Реклама — Медийные форматы (Узнаваемость и охват) и площадки

> Сводка по объекту «Узнаваемость и охват» — медийным (CPM/CPV) форматам VK Рекламы и площадкам, на которых они крутятся. Все числовые лимиты сверены с официальной справкой (ads.vk.com/help), у каждого блока указан слаг-источник. При обновлении — перепроверять по нему, а не по памяти.
>
> **Это НЕ перформанс.** Объект «Узнаваемость и охват» — оплата за показы (CPM) или, для In-stream видео, за просмотры (CPV). Оптимизация идёт на охват/частоту, а не на клики/конверсии. У медийного видео **другие** лимиты длительности и веса, чем у перформанс-видео из vk-ads-specs.md (там — до 60 сек / 90 МБ для универсальной записи). Здесь у большинства охватных форматов — **до 180 сек** (у Группы/профиля ОК — до 300 сек), при том же лимите веса 90 МБ. Не путать эти два набора спек между собой.
>
> **[MCP]** — заводится/настраивается через API VK Рекламы. **[UI]** — доступно только в кабинете ads.vk.com или на смежной платформе (Дзен-студия, ОК, MAX), через API недоступно.

## Общие механики объекта «Узнаваемость и охват»

Источник: `general/branding_ads/branding`

- Оплата **за показы** (CPM) и, для In-stream видео, **за просмотры** (CPV). [MCP]
- Управление **частотой показов** — на уровне кампании ИЛИ группы объявлений (не оба сразу). [MCP]
- Подключение **аудит-пикселей** сторонних верификаторов. [MCP]
- Управление **скоростью показов**: быстрое распределение (максимум показов за срок) vs равномерное (растянуть на весь период/день). [MCP]
- Атрибуция офлайн-конверсий по CRM-спискам — для объектов «Сайт» и «Видео и трансляции». [MCP]
- Стратегии ставок в охватных кампаниях: **Максимум показов** (рекомендуется, цена гуляет -50%/+100% от ставки), **Фиксированная ставка**, **Предельная цена**. Это отдельный набор стратегий от перформанс-кампаний («Минимальная цена» / «Предельная цена» — см. vk-ads-specs.md).
- Метрики медийки в дашборде (нужно включать вручную в настройке столбцов, уровень группы): «Частота на конец периода», «Прирост охвата», «Охват на конец периода».

Форматы внутри объекта «Узнаваемость и охват»: Баннерная реклама, Видеореклама, Пост/видео/клип/статья, Дзен, HTML5, Премиальное размещение, Группа и профиль ОК, Аудиореклама, Прямые сделки.

## Аудиореклама

Слаг: `general/branding_ads/audioads`

Реклама звучит перед прослушиванием аудиоконтента. Аудио можно загрузить своё или сгенерировать голосовым помощником Маруся **в кабинете** [UI] — это VK-нативная генерация, скиллом не используется (см. раздел про генерацию ниже).

- **Модель оплаты:** CPM — цена за 1000 прослушиваний. Прослушанным считается аудио, звучавшее **дольше 1 секунды**. [MCP]
- Целевое действие только одно — показы. Стратегии ставок: Максимум показов / Предельная цена / Фиксированная ставка.
- **Спеки:**
  - Аудио: 5–30 сек, вес ≤ 2 МБ.
  - Изображение: соотношение 1:1.
- В аудиоролике обязательно озвучивать законодательно требуемую информацию: дисклеймеры (мед./фин. услуги), реквизиты (дистанционная продажа), возрастная маркировка, сроки розыгрышей.
- Таргетинги — стандартные (гео, демография, интересы, ключевые фразы, пользовательские аудитории), места размещения лучше оставлять автовыбором.

## Баннерная реклама «Узнаваемость и охват»

Слаги: `general/branding_ads/branding_banner` (общий формат), `general/branding_ads/branding`

Продвигает статичные креативы и видео в одной кампании; максимальное покрытие мест размещения (соцсети, проекты VK, Рекламная сеть). Объект продвижения: сайт, мобильное приложение, сообщество ВКонтакте (для «Тизеров» — только сайт/сообщество).

- **Модель оплаты:** CPM, единственное целевое действие — показы. [MCP]
- Для объекта «Сайт» доступна атрибуция офлайн-конверсий по CRM-спискам.
- Распределение бюджета: быстрое (максимум показов за срок) / равномерное (растянуть на период или день).

**Требования к изображениям:**
| Параметр | Значение |
|---|---|
| Соотношения сторон | 1:1, 3:5, 4:5, 16:9, 9:16 |
| Разрешение | 1:1 — 600×600; 4:5 — 1080×1350; 16:9 — 1080×607 |
| Вес | ≤ 5 МБ |
| Формат | jpg, png |
| Текст на картинке | ≤ 20% площади |
| Логотип объявления | мин. 265×256 px |

**Требования к видео (медийный баннер — ОТЛИЧАЮТСЯ от перформанс-видео):**
| Параметр | Значение |
|---|---|
| Соотношения сторон | 1:1, 3:5, 4:5, 16:9, 9:16 |
| Мин. ширина | 600 px |
| **Длительность** | **до 180 сек** (не 60, как в перформансе) |
| Вес | до 90 МБ |
| Формат | mp4, mpeg, avi, mov |
| Разрешение | от 640×360 (рекоменд. 1280×720 / 1920×1080) |

Текстовые поля объявления: заголовок (сайт/сообщество ≤25, приложение ≤40), короткое описание ≤90, длинное описание ≤220 (необязательное), текст у кнопки (сайт/сообщество ≤25, приложение ≤40).

## HTML5-баннер

Слаг: `general/branding_ads/branding_html5`

Баннеры с анимацией на основе изображений и кода — интерактивнее статики. Единственное целевое действие — показы (CPM). [MCP] — заливка ZIP-архива и ссылок делается через кабинет/API как обычный медиафайл.

**6 форматов** и площадки:
| Формат | Площадки |
|---|---|
| html5_240x400 | Одноклассники, проекты VK, Рекламная сеть (десктоп, боковая колонка) |
| html5_100%x90 | Проекты VK, Рекламная сеть (десктоп, под поиском mail.ru) |
| html5_300x300 | Проекты VK, Рекламная сеть (десктоп, боковая колонка) |
| html5_300x600 | Проекты VK, Рекламная сеть (десктоп, боковая колонка) |
| html5_100%x300 | Проекты VK (мобайл, под новостями) |
| html5_300x250 | Рекламная сеть (мобайл, верх страницы) |

**Требования к ZIP-архиву (общие для всех форматов):**
- Один `index.html` + все ресурсы внутри архива; допустимые типы: png, jpg, jpeg, gif, css, js, svg.
- Вес архива: **≤ 150 КБ** (для «Премиального размещения» HTML5 — лимит выше, 200 КБ, см. ниже).
- Имена файлов — латиницей, текстовые файлы — utf-8.
- Обязательна кликабельная область с макросом `%link1%` (до 5 ссылок: `%link1%`…`%link5%`), ссылки открываются в новом окне: `<a href="%link1%" target="_blank">link1</a>`.
- Обязателен мета-тег размера: `<meta name="ad.size" content="width=240,height=400">`.
- Совместимость: IE 10+, Firefox 28+, Safari 6+, Chrome 18+, Edge, Opera 15+; для неподдерживаемых браузеров — упрощённая версия или gif-заглушка.
- Запрещены обращения к внешним ресурсам; контент занимает всю площадь без рамок; анимация ≤40% CPU в среднем / ≤60% в пике; ≤ 1 048 576 символов в креативе.
- **Safe-zones** (не размещать важную информацию): левый верхний угол 80×30 px (плашка «Реклама»), правый верхний угол 40×40 px (эдчойсы).
- Резинки: `100%x90` тянется от мин. 400 px; `100%x300` — от мин. 320 px.

Частые ошибки модерации: несколько `index.html` в архиве, внешние ссылки в CSS, отсутствие/неверный `ad.size`, некорректная кодировка, отсутствие макроса `%link1%`.

## Видеореклама-branding

Слаг: `general/branding_ads/branding_video`

Позволяет добавлять ролики **разных соотношений и длительностей в одну кампанию** — не нужно заводить отдельные кампании под каждый видеоформат. Размещается внутри видео, приложений, игр, на сайтах, в клипах.

### Подтипы и модель оплаты

| Подтип | Модель оплаты | Особенности |
|---|---|---|
| Все форматы | CPM (только показы) | Максимальный охват мест размещения |
| **In-stream** (ролик в видео) | **CPM или CPV** | CPM — платишь за старт воспроизведения; CPV — платишь только за 100%-й досмотр ИЛИ клик по видео. Формула CPV = расходы / кол-во просмотров. Пользователь может пропустить ролик — тогда списания нет |
| В Клипах | CPM (только показы) | Вертикальный формат |

### Матрица длительностей/соотношений (медийное видео — НЕ путать с перформанс-90МБ/60сек)

| Подтип | Соотношения | Длительность | Вес | Мин. ширина |
|---|---|---|---|---|
| Все видеоформаты | 1:1 (до 30 и 180 сек), 9:16 (до 180 сек), 4:5 (до 30 сек), 16:9 (до 6 и 180 сек) | см. по соотношению | ≤ 90 МБ | 600 px |
| In-stream | 16:9 | 6–30 сек (рекоменд. набор 6/10/15/20 сек) | ≤ 90 МБ | 600 px |
| В Клипах | 9:16, 4:5, 1:1 | — | ≤ 90 МБ | 600 px |

Формат файла везде: mp4, mpeg, avi, mov. Разрешение — от 640×360 (рекоменд. 1280×720 / 1920×1080). Безопасные зоны сюжета: избегать важных элементов в 15% от верхней границы кадра и 25% от нижней.

Текстовые поля: логотип ≥256×256 px, заголовок (сайт/сообщество ≤25, приложение ≤40), короткое описание ≤90, длинное описание ≤220 (опц.), текст у кнопки (≤25/≤40).

## Пост, видео, клип, статья

Слаг: `general/branding_ads/branding_video_content`

Продвигает уже опубликованный контент от авторов/сообществ ВКонтакте (посты, видео, клипы, трансляции) — размещается в лентах VK, ОК, на территории Дзен. **Модель оплаты — CPM.** [MCP]

- Объекты выбора: Пост / Клипы / Видео и трансляции; в этом же меню находятся под-форматы «Группа или профиль ОК» и «Дзен» (описаны отдельными разделами ниже).
- Пост не должен быть уже помечен «Реклама от автора», не иметь соавторов; опрос в посте — ≤5 вариантов ответа и ≤1 вложение.
- Клипы — только последние 100, не закрытые приватностью, без эмодзи в описании.
- Видео/трансляции — краткое описание ≤90 знаков, без эмодзи, ≤2 переноса строки.
- Атрибуция офлайн-конверсий доступна для объекта «Видео и трансляции».
- Метрики: медийные (частота/прирост/охват) на уровне группы + отдельные метрики клипов (лайки, комментарии, поделились, закладки).

## Дзен — медийный формат

Слаги: `general/branding_ads/branding_dzen`, `general/dzen/counter`, `general/dzen/dzen_tips`, `general/dzen/scroll_to_site`, `general/dzen/promo_dzen`, `general/dzen/video_promo_dzen`

Промо в Дзене — рекламный объект для продвижения статей, каналов и видео в контентной платформе Дзен, настраивается из кабинета VK Рекламы.

### Обязательная привязка кабинета [UI-гейт]

Перед запуском нужно связать кабинет VK Рекламы и канал в Дзене:
1. Зайти в Дзен-студию → раздел «Продвижение» → там уже подставлен ID кабинета VK Рекламы → нажать «Перейти в VK Рекламу» → «Разрешить доступ». [UI]
2. Связка 1:3 в обе стороны — один канал Дзена можно привязать максимум к 3 кабинетам VK Рекламы, и наоборот.

Это делается **только в интерфейсе** Дзен-студии — через MCP/API привязку не завести.

### Форматы и оплата

| Что рекламируем | Раздел | Модель | Мин. ставка |
|---|---|---|---|
| Статья (медийный охват) | «Узнаваемость и охват» → Пост/видео/клип/статья → Дзен → «Статья» | CPM | от 110 ₽/1000 показов |
| Канал (подписки) | «Узнаваемость и охват» → …→ Дзен → «Канал» | CPM | от 110 ₽/1000 показов |
| Брендированная статья | доступно **по запросу** на dzen_sales@lists.vk.team | CPM | — |
| Видео в Дзене | Целевое действие «Продвижение видео» | CPM | от 70 ₽/1000 показов |
| Статья/канал — перформанс-охват (для сравнения, НЕ этот файл) | вкладка «Целевые действия» | CPC | ~5–7 ₽/клик |

- **Мин. бюджет кампании в Дзене — 10 000 ₽** (день или весь срок) — жёсткое ограничение, отличается от общего минимума VK Рекламы в 300 ₽ (см. vk-ads-specs.md).
- Для рекламы статей таргетинги «Интересы и поведение» доступны; «Места размещения» — не выключать автовыбор, иначе реклама не уйдёт на территорию Дзена.
- Гиперлокальный продукт (город < 500 000 чел.) — Дзен как инструмент может не подойти; рекомендуется федеральный охват или несколько крупных регионов.

### Объявление из статьи/канала

- Статья: обложка = первая картинка статьи, заголовок ≤70 знаков (важно — заголовок в самой статье тоже надо ужать до 70 знаков в Дзене, иначе кабинет выдаст предупреждение), текст объявления = первые 170 знаков статьи. Правки статьи требуют остановки кампании → правки в Дзене → **новая** кампания (иначе статистика в Дзене собьётся).
- Канал: карточка — заголовок ≤40, описание ≤25, фон-изображение 600×600 / 1080×607 / 1080×1350 (рекоменд. от 1200×1600), png/jpg, не полностью чёрное/белое; соотношение карточки — 3:4.
- Видео: заголовок ≤70; видеоплеер + кнопка + обязательные метки «Промо»/«Реклама»/возрастная.
- Эмодзи в объявлениях Дзена — запрещены **полностью** (жёстче общего лимита ≤5 из vk-ads-specs.md).

### Рекламные пиксели в статье [UI]

Ставятся не в VK Рекламе, а **в самой статье на территории Дзена** (кнопка «Добавить рекламный пиксель» в Дзен-студии) — на 3 события: открытие, полное прочтение, внешний переход по ссылке. Список поддержанных счётчиков обширный: TNS/Mediascope, AdRiver, Weborama, AdFox, DoubleClick, Яндекс.Метрика (mc.yandex.ru), ScoreCardResearch, Adloox, DoubleVerify, rs.mail.ru и др. (полный список — источник general/dzen/counter).

### Scroll-to-site

Технология бесшовного перехода со статьи на сайт/канал по клику **именно на рекламное объявление** (для органического трафика не работает). Настраивается в Дзен-студии внутри статьи после привязки кабинетов [UI]; на стороне VK Рекламы отдельных настроек не требует.

### Советы по запуску (dzen_tips)

- Кому НЕ подойдёт: узкий сегмент аудитории, гиперлокальный бренд, b2b, нет выгодного оффера, неактивный/отсутствующий канал.
- Средние ориентиры: для цели «Показы» — CTR от 1%, дочитывания от 30%; для цели «Продвижение статьи» — CTR от 1,3%, дочитывания от 37%.
- Оптимальная длина статьи — 2000–4000 знаков; запускать минимум 5 статей с разной подачей для сравнения подходов.

## Группа и профиль ОК

Слаги: `general/branding_ads/branding_ok_groups` (медийный, CPM), `general/network/ok_groups` (перформанс-версия с целями «Вступление»/«Подписка»/«Сообщение»/«Продвижение публикации» — CPC/CPM смешанно)

Медийная версия (раздел «Узнаваемость и охват» → «Пост, видео, клип, статья» → «Группа или профиль ОК»):

- **Модель оплаты:** CPM, единственное целевое действие — показы. [MCP]
- Реклама размещается **только в ленте Одноклассников** (мобильная + веб), автовыбор мест размещения здесь не расширяет охват за пределы ОК.
- Объявление формируется автоматически из поста: заголовок = название группы/профиля, текст = текст поста, картинка = картинка поста.
- Требования к изображению: 1:1 (600×600) или 16:9 (1080×607), ≤5 МБ, jpg/png.
- Требования к видео: 1:1 / 16:9, мин. ширина 600 px, **длительность ≤300 сек** (это дольше, чем у баннерной/видео-branding — там 180 сек), ≤90 МБ, mp4/mpeg/avi/mov.
- Для продвижения личного профиля в ОК (через перформанс-объект, не через медийный) — гейт: страница привязана к тому же VK ID, что и кабинет, открыта для всех, создана ≥40 дней назад, включена 2FA. Запуск рекламы профиля ОК из кабинета агентства/клиента агентства технически невозможен.

## Премиальное размещение

Слаг: `general/branding_ads/premium_ads`

Набор форматов на самых заметных позициях — HTML5-баннеры (та же техническая база, что и у обычного HTML5-баннера, но лимит архива **200 КБ**, а не 150 КБ).

| Формат | Размещение | Площадки |
|---|---|---|
| Билборд | Шапка страницы (десктоп/мобайл/все устройства) | Рекламная сеть, Новости Дзена |
| В Дзене — над статьями | Десктоп/мобайл | Дзен |
| В Дзене — под контентом | Десктоп/мобайл/все устройства | Дзен, Новости Дзена |
| На весь экран | Десктоп | Проекты VK, Рекламная сеть |
| 240px × 100% | Десктоп | Почта mail.ru (правая колонка) |

- **Модель оплаты:** CPM. Стратегии — Максимум показов / Фиксированная ставка / Предельная цена.
- ZIP-архив: как у HTML5-баннера (index.html + ресурсы, латиница, utf-8, макрос `%link1%`, тег `ad.size`), но лимит веса — **≤200 КБ**.
- Для Билборда и «В Дзене» нужно дополнительно выбрать устройства показа.

## Прямые сделки

Слаг: `general/branding_ads/direct_transactions`

Агентский инструмент: агентство и его клиенты размещают рекламу на выбранных площадках паблишеров (поставщиков трафика) Витрины VK Рекламы, стоимость и условия согласуются напрямую с паблишером. [MCP для заведения кампании] + [UI для согласования сделки через Витрину/партнёрский кабинет]

- Требуется агентский кабинет.
- Доступные форматы сделки: Ролик в video (In-stream), Мультиформат (Smart TV — анонсирован, ещё не доступен).
- **Минимальная ставка CPM не может быть ниже аукционной цены VK Рекламы**: от 180 ₽ для In-stream, от 70 ₽ для Мультиформата.
- Флоу: заявка через раздел «Заявки» или карточку паблишера в «Витрине» → согласование паблишером в партнёрском кабинете → кампания заводится из кабинета клиента-участника сделки, вкладка «Узнаваемость и охват» → «Прямые сделки». В группе объявлений выбирается конкретная сделка (одна на группу) + обычные таргетинги VK Рекламы, но покупаются только показы по условиям сделки.

## Аудит-пиксели и верификаторы показов

Слаг: `general/branding_ads/verifiers`

Аудит-пиксель — сторонний счётчик для независимой верификации показов, подключается **только для кампаний объекта «Узнаваемость и охват»**, на уровне группы объявлений (блок «Дополнительные настройки», вставить ссылку). [MCP]

- В одну группу — одна ссылка на конкретного верификатора; можно добавить несколько ссылок, если верификаторы разные. Пиксель считает статистику по группе целиком — для пообъявленной статистики нужна отдельная группа на каждое объявление.
- Верифицированные вендоры: **Weborama, AdRiver, Adserving, Adloox, Mediascope, TargetADS.**
- «Видимость показов» — доп. опция (объявление засчитывается видимым при ≥50% площади в кадре ≥1 сек, для видео ≥2 сек); может тарифицироваться верификатором отдельно. Пока недоступна для Дзена и промопостов ВКонтакте.
- Набор поддерживаемых событий по вендору: у Weborama/AdRiver/Adserving/TargetADS — показы, старт видео, 25/50/75%, полный досмотр, видимость; у Adloox — только показы; у Mediascope — аудиторные данные.

## Продвижение музыки ВКонтакте

Слаг: `general/network/music`, документы: `general/network/how_to_add_music`

Объект «ВКонтакте, ОК, Mini Apps, Дзен, MAX» → «Музыка». Целевое действие только одно — «Старт прослушивания». Реклама транслируется только на территории ВКонтакте. [MCP]

**[UI-гейт] Лицензионные документы — обязательны ДО запуска:**
- Юрлица — лицензионный договор.
- Физлица — копия паспорта + гарантийное письмо (шаблон VK) об авторских правах.
- Загружаются один раз на кампанию; без документов запустить рекламу невозможно.

Также перед запуском трек должен быть официально размещён в VK Музыке через агрегатора (Believe, ONErpm, Tunecore, ZVONKO digital и др.) или лейбл — без этого карточки музыканта и трека не будет. Это отдельный внешний процесс, не связанный с VK Рекламой напрямую.

В объявлении можно продвигать до 10 файлов (9 аудио + обложка) или плейлист; изображение/видео — по общим спекам мультиформата. Эмодзи в описании — ≤5.

## Личный профиль ВКонтакте

Слаги: `general/network/profile`, `general/network/profile_settings`

**[UI-гейт] Перед продвижением страница обязана быть:**
- **подтверждена** (через Госуслуги / Alfa ID / Tinkoff ID / Sber ID, бесплатно, 14+);
- **открыта для всех** (Настройки → Приватность → Тип профиля → «Открытый»);
- **создана не менее 40 дней назад**;
- защищена **двухфакторной аутентификацией (2FA)**.

Все 4 условия настраиваются только в самом ВКонтакте (id.vk.com / vk.com/settings), через API VK Рекламы это не проверяется и не включается — скилл может только напомнить чек-лист.

Кампания заводится через объект «ВКонтакте, ОК, Mini Apps, Дзен, MAX» → «Сообщество, группа или профиль»: цели — «Подписка на профиль», «Отправка сообщения», «Реакция на пост» (оплата CPC/CPM в зависимости от цели — это уже больше перформанс-механика, но использует ту же площадку и тот же гейт по профилю). Продвижение профиля клиента требует связки двух кабинетов VK Рекламы (таргетолог + владелец) через раздел «Настройки» → «Права доступа».

## Мини-приложения, каналы ВК/MAX и другие network-объекты

Слаг: `general/network/mini_app`

- **VK Mini Apps и игры**: объект «ВКонтакте, ОК, Mini Apps, Дзен, MAX» → «Mini Apps и игры». Целевое действие по умолчанию — «Запуск мини-приложения»; если в приложении размечены доп. события (подписка, регистрация, покупка, лид и т.д.) — они подтягиваются автоматически как цели. Модель оплаты — как у перформанс-кампаний (CPC/CPA), не CPM. Продвигать можно чужое мини-приложение (без прав администратора). Место размещения — только лента ВКонтакте.

Слаг: `general/network/promo_channel`

- **Каналы ВКонтакте и MAX**: объект «ВКонтакте, ОК, Mini Apps, Дзен, MAX» → «Каналы». Канал ВКонтакте — цель «Вступление в канал» (оптимизация на подписки). Канал MAX — **только** цель «Клики по рекламе» (CPC), оптимизации на подписку нет.
  - **[UI-гейт] Канал MAX должен быть публичным** — создание публичного канала доступно юрлицам/ИП/самозанятым, подключённым к платформе MAX для партнёров и прошедшим верификацию, либо тем, у кого есть ресурсы с меткой А+ на других площадках (VK, ОК, Дзен, Telegram). Настраивается вне VK Рекламы, на dev.max.ru.
  - Продвижение канала в Дзене — отдельный флоу, см. раздел «Дзен» выше (`general/dzen/promo_dzen`).

## Генерация креативов — вне scope MCP

VK Реклама предлагает встроенные инструменты генерации в кабинете: голосовой помощник Маруся для аудиорекламы, текстовый автогенератор описаний/заголовков, умное кадрирование, дорисовка изображений, апскейл, галерея готовых фото. Все они работают **только в UI кабинета** и не имеют API-эндпоинтов — скилл vk-ads-manager их не вызывает и не заменяет. Генерация креативов (текст/картинка/видео) для загрузки в объявления делается собственным внешним пайплайном скилла, а готовые файлы затем заливаются через API как обычные медиафайлы.
