# Buyer Personas для VK Рекламы

VK Реклама работает с аудиториями, и для VK особенно важно **поведение в соцсети**. Для каждой персоны нужно понимать не только демографию, но и **что человек делает в VK**.

## Структура персоны

```markdown
## P1: <Название персоны>

### Кто это
- Возраст: 28-38
- Пол: 70% женщины, 30% мужчины
- Доход: средний (~70-120 тыс/мес)
- Образование: высшее, часто гуманитарное
- Семейное положение: 50% в отношениях, 30% женаты/замужем, 20% одиночки
- География: Москва, СПб, миллионники
- Должность: SMM-специалист на фрилансе или в малом агентстве

### Поведение в VK (специфично!)
- Какие сообщества читает: «SMM с нуля», «Контент-мейкер», «Психология фрилансера», «Скиллбокс»
- Какой контент смотрит: образовательные ролики, кейсы коллег, посты с лайфхаками
- Активность: 2-3 часа в день в VK, в основном — лента и Клипы
- Покупает: курсы (раз в 6-12 мес), инструменты (раз в 3 мес)
- Использует: VK Маркет нечасто, в основном — личные сообщения

### JTBD (Job To Be Done)
«Когда у меня 5+ клиентов, я хочу автоматизировать рутину генерации постов, чтобы тратить время на стратегию и общение с клиентами, а не на однотипные посты»

### Боли
- Рутина высасывает время (генерация постов 4-6 часов/день)
- Креативное выгорание
- Низкий чек на типовых проектах
- Сложно масштабировать (нанимать дорого)

### Возражения
- «AI генерит шаблонно — клиент заметит»
- «Уже пробовал ChatGPT — не подходит»
- «Дорого, не отобьётся»
- «Сложно настроить, нет времени учиться»

### Триггеры покупки
- Кейс коллеги-фрилансера с конкретными цифрами
- Демо «вот так это выглядит за 5 минут»
- Триал / возврат денег
- Срочный дедлайн от клиента
- Появление нового крупного клиента (нужно масштабироваться)

### 5-10 гипотез аудиторий
- LAL 1% от платных клиентов нашего сервиса
- Подписчики сообществ: «SMM-специалист», «Контент-мейкер», «SMMplanner blog»
- Интерес «SMM и маркетинг» + соцдем 25-40 + женщины
- LAL от посетителей блога SMMplanner / других конкурентов
- Ключевые фразы: «контент-план», «генератор постов», «как создать пост для инстаграм»
- Пользователи фриланс-бирж (если VK даёт такую категорию)
- Подписчики Skillbox / Нетологии / GeekBrains курсов по SMM
- Молодые мамы 25-35 с интересом «бизнес и маркетинг» (часто фрилансят)
```

## Типичные персоны для разных типов бизнеса

### B2B SaaS / инструменты для специалистов
- P1: Линейный специалист на фрилансе / в малой команде (главное)
- P2: Эксперт / консультант с курсами / личным брендом
- P3: Тим-лид / руководитель отдела в среднем бизнесе

### B2C массовка
- P1: Молодые активные пользователи (18-30, ядро аудитории)
- P2: Семейные с детьми (28-45, чувствительные к цене)
- P3: Старший сегмент (45-60, лояльные, но осторожные)

### B2C премиум / lifestyle
- P1: Self-employed профессионалы 30-45 с высоким доходом
- P2: Корпоративный менеджмент 35-50
- P3: «Старые деньги» 50+ с устоявшимися привычками

### Локальный сервис
- P1: Жители конкретного района / города (геотаргетинг)
- P2: Работающие рядом (день — в офисе у нас)
- P3: Гости города / туристы (если применимо)

### Инфобиз / образование
- P1: Те кто уже учился — ретаргет с апсейлом
- P2: Те кто ищет первое образование в нише
- P3: Те кто меняет профессию

## VK-специфичные «зацепки» для персон

В VK можно таргетить такие вещи которых нет в Директе / Meta:

### Соцграф
- Семейное положение (в отношениях / женат / разведён) — для дейтинг-сервисов, ювелирки, юр.услуг
- Учебное заведение и год выпуска — для образовательных продуктов, реюнионов
- Место работы (если указано) — для B2B
- Религия (заполнено сильно реже, но есть)
- Знание языков — для образовательных, тревел-продуктов
- Подписки на крупных блогеров — для нишевых ЦА

### Поведение в экосистеме
- Какие сообщества активно посещает (можно таргетить на конкретные)
- Что лайкает / комментит
- Покупает ли в VK Маркете
- Сколько времени в день в VK
- Использует ли Клипы (это важный сигнал для молодёжных продуктов)
- Активность в Дзене / Mail.ru

### Технические
- Тип устройства (iOS / Android / Desktop)
- Версия ОС (для приложений)
- Местоположение по геолокации (если разрешено)
- Дни недели и часы активности

## Антипаттерны

### Не делать
- **Размытые персоны** типа «активные молодые люди 18-45 интересующиеся всем» — нет.
- **Слишком много персон** (> 5) — невозможно тестировать.
- **Персоны на основе своих фантазий** без проверки. Лучше — 2 интервью с реальными клиентами.
- **Игнорирование behavior** — без понимания что юзер делает в VK гипотезы аудиторий мусорные.
- **Одинаковые JTBD для разных персон** — значит это одна персона.

### Делать
- **3 персоны (макс 5)** с чётким различием
- **JTBD как формула «Когда [контекст], я хочу [действие], чтобы [результат]»**
- **5-10 конкретных гипотез аудиторий** на персону — это вход в Шаг 6.5
- **Боли и возражения отделить** — это разное. Боль — про текущую ситуацию. Возражение — про предложение.
- **Триггеры покупки** — конкретные события / эмоции / контексты

## Связь с матрицей аудиторий (Шаг 6.5)

Для каждой персоны → 3 ячейки матрицы (Hot / Warm / Cold):

```
P1 → Hot ячейка   (LAL 1% от платных клиентов)
P1 → Warm ячейка  (сообщества + интересы)
P1 → Cold ячейка  (соцдем + 1 широкий интерес)
```

Итого для 3 персон = 9 ячеек, но реально заполняешь 4-6 самых сильных. См. `targeting-strategy.md`.
