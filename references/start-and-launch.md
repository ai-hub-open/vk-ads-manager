# VK Реклама — Начало работы: запуск, лимиты, статусы, операции

> Про процесс запуска и операционные факты. Подробные спеки форматов объявлений, модерации и ОРД — см. `vk-ads-specs.md`. Про иерархию сущностей API (`ad_plan`/`campaign`/`banner`) и REST-эндпоинты — см. `vk-ads-api.md`. Про MCP-инструменты — см. `vk-ads-mcp-integration.md`.

## Развилка: как запускать

**[UI]** В кабинете VK Рекламы при создании кампании есть две вкладки: «Быстрый запуск» и «Режим эксперта».

### Быстрый запуск (смарт-кампании) — `general/start/smart_campaign`

Упрощённый тип кампаний: указываешь объект (сообщество, профиль, сайт, каталог, визитка) и краткое описание предложения — аудиторию, изображение и текст система подбирает автоматически. Целевые действия ограничены: подписка, сообщение, продвижение поста, переходы на сайт, продвижение товаров/услуг, клики по визитке.

Когда уместно: малый/средний бизнес, быстрые тесты гипотез, нет времени/данных на ручную настройку. Из смарт-кампании в любой момент можно нажать «Перейти в ручную кампанию» и получить режим эксперта с уже заданными настройками.

**[MCP] Ограничение:** быстрый запуск — чисто интерфейсная функция кабинета (автоподбор через мастер), через API/MCP так не создать. Наш скилл работает через режим эксперта — ручное создание `ad_plan → campaign → banner`.

### Режим эксперта — `general/start/expert_mode`

Расширенный режим: полный выбор цели, детальная настройка аудитории, ставок, форматов, мест размещения. Это основной путь скилла — соответствует полю `objective` и ручной сборке структуры через API.

Доступные типы рекламы: **перфоманс** (сайт, лиды, установки, покупки, подписки, сообщения — оптимизация под конверсии) и **медийная/охватная** (баннеры, видео, посты — оптимизация под охват/узнаваемость, вкладка «Узнаваемость и охват»). Для перфоманса — вкладка «Целевые действия».

## Этапы создания — `general/start/creating`

Трёхуровневая структура кабинета: **Кампания → Группа объявлений → Объявление**. Соответствие сущностям API: Кампания = `ad_plan` (цель + общий бюджет), Группа = `campaign` (таргетинги, плейсменты, дневной бюджет, нужен `ad_plan_id`), Объявление = `banner` (текст+медиа, нужен `campaign_id`). Полная схема полей и REST-запросов — в `vk-ads-api.md`.

Порядок настройки в кабинете:
1. **Кампания** — тип рекламного объекта (приложение/сайт/каталог/…), целевое действие, оптимизация бюджета (вкл. по умолчанию), стратегия ставок, бюджет и период.
2. **Группа объявлений** — расписание показа, регионы, демография, интересы/поведение, пользовательские аудитории, устройства, места размещения, UTM.
3. **Объявление** — универсальные объявления (система сама собирает форматы под площадки из загруженных картинок/видео), тексты, медиа, ссылка, кнопка.

**Важно [MCP]/[UI], одинаково для API и кабинета:** цель (`objective`) и рекламируемый объект **нельзя изменить после запуска кампании** — технически не предусмотрено. Если нужна другая цель/объект — создаётся новая кампания (`ad_plan`), а не редактируется существующая.

## Лимиты объявлений — `general/start/ad_limits`

Два вида лимита, оба считаются в объявлениях (`banner`), не в кампаниях/группах:

- **Общий лимит.** Новый аккаунт — до 300 объявлений. Растёт с балансом/тратами: если баланс или траты за последние 3 месяца превышают 3000 ₽, то за каждые дополнительные потраченные 150 ₽ добавляется +1 доступное объявление. Пример: траты за 90 дней 5000 ₽ → лимит 313. Число доступных/созданных объявлений видно в кабинете при создании кампании (недоступно для юрлиц).
- **Дневной лимит.** Максимум 200 объявлений в сутки — жёсткий технический потолок независимо от общего лимита. Если общий лимит позволяет 320, в один день всё равно можно создать не больше 200.

**[MCP] Практика:** при массовом заливе через API (например, 5+ групп × 5 объявлений = 25+ баннеров) лимит редко становится проблемой на старте, но стоит учитывать при регулярных ротациях креативов на аккаунтах с малым балансом — там общий лимит может быть близок к 300.

## Лимиты бюджета — `general/start/budget_limits`

Бюджет обязателен независимо от стратегии ставок — без него кампанию не запустить.

- **Минимум:** 300 ₽ и для дневного, и для общего лимита. Для продвижения в **Дзене — 10 000 ₽**.
- **Общий лимит (за всё время)** — требует обязательной даты окончания кампании; по достижении показы останавливаются.
- **Дневной лимит (за день)** — показы приостанавливаются при достижении лимита, возобновляются автоматически в 00:01 следующего дня при наличии средств. Отсутствие дневного лимита при заданном общем бюджете может привести к быстрому «сжиганию» всего бюджета до даты окончания.
- Если бюджет < 500 ₽, итоговый расход может немного превысить лимит (на стоимость последнего клика/показа).

## Статусы кампаний, групп и объявлений — `general/start/campaign_status`

Статус наследуется снизу вверх: статус группы зависит от статусов её объявлений, статус кампании — от статусов её групп.

- **Черновик** — не опубликована.
- **На проверке** — на модерации. Если хотя бы одно объявление в кампании прошло модерацию, статус кампании — «Действующая».
- **Ожидает дату запуска** — ждёт даты старта.
- **Собираем данные** — статистика ещё не отображается (обычно ~1 день после создания).
- **Активна** (зелёный) / **Активна с ошибками** (жёлтый, есть проблема, но показы идут) — кампания активна, пока активна хотя бы одна группа; группа активна, пока активно хотя бы одно объявление.
- **Ошибки в настройках** — не работает из-за ошибки конфигурации.
- **Не показывается** — показ приостановлен по иной причине (см. пояснение в кабинете).
- **Остановлена** — вручную выключена тумблером. Статус кампании — «Остановлена», если нет ни одной активной группы, но есть хотя бы одна остановленная (аналогично для группы/объявлений).
- **Баланс аккаунта исчерпан** / **Не хватает средств** (остались только бонусы) — возобновится автоматически после пополнения.
- **Приостановлена по дневному лимиту** — до начала следующих суток или ручного увеличения лимита.
- **Достигнута дата остановки** — показ завершён по расписанию, можно продлить.
- **Завершена** — исчерпан бюджет на весь срок или прошла дата окончания.
- **Удалена** — архивирована (см. раздел про удаление ниже).
- **Отклонена** — не прошла модерацию, аккаунт неактивен.
- **Недоступна** — формат объявления отозван либо отозван SKAdNetwork ID группы; менять настройки/добавлять объявления нельзя.

**Автоудаление:** кампании без показов и кликов в течение **180 дней** автоматически переводятся в статус «Удалена».

**[MCP] Для API:** соответствующее поле статуса на бэкенде — `blocked` (черновик/остановлена) / `active` / `deleted` для `ad_plan`/`campaign`, и `moderating` / `accepted` / `rejected` / `blocked` для `banner`. При создании через `vk_ads_api.py` структура сначала создаётся в `status: blocked`, активация — отдельным `PUT` с `status: active`.

## Операции с сущностями

### Копирование — `general/start/copy` [UI]

Копировать можно кампанию, группу и объявление — через иконку «⋯» → «Дублировать» (для кампании также доступна кнопка «Скопировать существующую» на экране создания). Копия наследует все настройки и креативы исходника; кампанию после копирования нужно донастроить и опубликовать. Чисто интерфейсная операция кабинета; через API аналог — прочитать сущность и создать новую с теми же полями.

### Редактирование — `general/start/edit_campaign`

Точечное редактирование — через карандаш у названия сущности. **Массовое редактирование [UI]** — до **50 объектов за один раз** через меню «Действия» → «Редактировать»: для кампаний доступны название/бюджет/стоимость конверсии/даты, для групп — то же плюс таргетинги и плейсменты, для объявлений — тексты, ссылка, кнопка, медиафайлы. Если часть объектов нельзя изменить массово по какой-то категории настроек — недоступной становится только эта категория, а не вся операция.

**[MCP]:** массовое редактирование через API — это просто последовательные `PUT`-запросы к нужным `ad_plan_id`/`campaign_id`/`banner_id`; технического лимита в 50 штук на уровне API нет, это ограничение только UI-инструмента массовых действий.

### Удаление и восстановление — `general/start/delete_campaign`

Удаление архивирует сущность (статус «Удалена»), каскадно — вниз по иерархии: удаление кампании архивирует все её группы и объявления, удаление группы — все её объявления. Восстановление возвращает последний статус, который был у сущности и вложенных элементов перед удалением, тоже каскадно.

Отдельно от ручного удаления: кампании без показов/кликов за **180 дней** автоматически получают статус «Удалена» (см. выше).

## Предпросмотр объявлений — `general/start/banner_preview` [UI]

Доступен на дашборде (вкладка «Объявления», иконка глаза на миниатюре) и в режиме редактирования объявления — оба варианта показывают, как объявление выглядит в разных плейсментах (лента, видео и т.д.) и форматах, до и после запуска.

Если объявление уже запущено — можно посмотреть, как оно выглядит непосредственно на площадке (ВКонтакте/ОК/Дзен): нужна авторизация в соответствующей соцсети, объявление подгрузится туда на 10 минут, игнорируя таргетинги по полу/возрасту/гео. Для ОК нужна регистрация на площадке от 14 дней.

Предпросмотр недоступен если: объявление удалено/остановлено, не прошло модерацию, на балансе нет денег, формат не соответствует месту размещения, нет авторизации на нужной площадке.

Практическая польза для нашего флоу: после заливки через API стоит зайти в кабинет и прогнать созданные объявления через предпросмотр перед тем, как переводить кампанию в `active` — это последняя ручная проверка форматирования и обрезки картинок, которую API не покажет.

## Помощь таргетологов VK — `general/start/targetologists`

Фолбек, если что-то не удаётся решить самостоятельно: бесплатная консультация специалистов VK по цели, аудитории, форматам и текстам/изображениям — писать в сообщество [vk.me/target_vk_ads](https://vk.com/away.php?to=http%3A%2F%2Fvk.me%2Ftarget_vk_ads&utf=1), ответ обычно за 3-5 рабочих дней. Использовать как крайнюю меру при спорных кейсах модерации или неочевидных настройках — не как замену этому скиллу.

## Мини-чек-лист «перед созданием»

- [ ] Определились: смарт-кампания (быстрый тест) или режим эксперта (наш путь) — general/start/smart_campaign, expert_mode
- [ ] Цель (`objective`) и рекламируемый объект зафиксированы окончательно — после запуска не меняются, только новая кампания
- [ ] Бюджет ≥ 300 ₽ (≥ 10 000 ₽ для Дзена), стратегия ставок выбрана
- [ ] Прикинуто количество объявлений в структуре — укладывается в общий лимит (300+) и дневной лимит (200/сутки) аккаунта
- [ ] Иерархия готова: `ad_plan` (кампания) → `campaign` (группа, с `ad_plan_id`) → `banner` (объявление, с `campaign_id`)
- [ ] После заливки — прогнать объявления через предпросмотр в кабинете перед активацией
- [ ] Знаем, куда идти при спорной модерации/сложном кейсе — таргетологи VK как фолбек
