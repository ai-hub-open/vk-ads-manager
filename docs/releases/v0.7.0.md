# v0.7.0 — установка плагином Claude Code

Обновление с v0.6.8. Воронка подготовки и работа с активной кампанией не менялись.

**Плагин Claude Code.** Скилл теперь можно поставить из маркетплейса ai-hub-open — тогда новые
версии приходят через `/plugin`, без ручной переустановки. В сессии Claude Code:

```
/plugin marketplace add ai-hub-open/claude-plugins
/plugin install vk-ads-manager@ai-hub-open
```

Скилл вызывается как `/vk-ads-manager:vk-ads-manager` или просьбой своими словами. Чтобы
обновления приходили сами: `/plugin` → **Marketplaces** → `ai-hub-open` → **Enable auto-update**.

- Python-зависимости плагин сам не ставит: один раз выполните `python install.py` в папке плагина
  (путь покажет `/plugin` → vk-ads-manager).
- Ключи хранятся в `~/.vk-ads-manager/`, вне папки плагина, — обновления их не стирают.
- Если раньше скилл лежал папкой в `~/.claude/skills/vk-ads-manager`, удалите её — иначе скилл
  загрузится дважды.

**Сообщение о новой версии.** В начале разговора скилл сверяет свою версию с GitHub. Если вышла
новая — одним сообщением скажет, что изменилось и как обновиться, и спросит, обновиться сейчас
или продолжить. Без интернета проверка молча пропускается. Сам себя скилл не обновляет —
обновление ставите вы.

**Архив к релизу.** Начиная с этой версии к каждому релизу приложен готовый
`vk-ads-manager.skill` — для Claude Desktop, claude.ai и установки папкой.

## Обновление

Claude Code с плагином — как выше. Claude Desktop и claude.ai — скачайте
`vk-ads-manager.skill` из этого релиза и загрузите заново вместо старого.
