## Что нового в 0.7.12

Обновление с v0.7.11.

**Кампания в VK Рекламе создаётся с первого раза.** Раньше агент собирал запрос на создание кампании по неточным образцам и получал от VK по несколько отказов подряд: то бюджет задан дважды, то у группы нет цели, то выбрана стратегия ставок, которую VK не принимает. Каждую ошибку он исправлял сам, но на это уходило время, а иногда и терпение пользователя. Теперь в скилле один образец кампании, проверенный на живом кабинете:

- у кампании и у всех её групп одна и та же цель, выбранная вместе с пакетом размещения;
- у кампании один бюджет — на весь тест или на день, а дневной бюджет распределяется по группам;
- стратегию ставок агент не выбирает: VK ставит её по пакету, а вы можете поменять её в кабинете до запуска;
- объявление собирается только из текста, ссылки, картинки и логотипа — без служебных полей, которые VK отвергает;
- логотип — не шире 256 пикселей, кнопка — из списка, который принимает VK.

Если VK всё же откажет, у агента есть таблица отказов с готовым исправлением: он поправит запрос один раз и не будет перебирать варианты.

**Залив без MCP временно — только по инструкции.** Скрипты прямого залива через API собирают кампанию в устаревшей форме, и VK её не создаст. Пока их не исправили, без подключения MCP агент сразу готовит пошаговую инструкцию для ручной загрузки.

**Что не изменилось.** Кампания, группы и объявления по-прежнему создаются на паузе, удаления нет, запуск — только по вашей явной команде в кабинете.
